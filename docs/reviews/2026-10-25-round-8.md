- ナイル调查：64.1% 是多选题里"用的人最多"，不是"第一信息来源"；98.1%、69.2% 这几个数原报告没给分母
- Porter 那条：页面是 Anthus（anth.us，AI 工程咨询公司）发的，不是 Jev 的开发方，Jev 是 TypeSafe 的；测的是通用版 GPT-6 Luna，不是 Decisions API 本身；页面没署名，作者待确认
- RRSI："省 30% token"是和不加正则化的自我改进比，和原始 harness 比反而更贵；作者来自 Google Cloud AI Research 和三所大学，仓库写明不是 Google 官方产品
- 不在标题里、写在溯源说明里的：Postgres 那条说"UNLOGGED 表所有读写都在内存里"不对，只是不写预写日志，数据照样落盘；mizchi 猜"Opus 4.5 学了 Claude Code 的数据"，按条款最多对应 2025-09-28 之后约两个月的会话
