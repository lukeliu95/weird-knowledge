# 弱关系复核抽查单

从 787 处判成「成立」的里随机抽 10 处。每处回「认」或「不认」，或者只回不认的编号。

**1. Codex 28天做出Sora安卓版**
- 源知识：语言模型是少样本学习者（GPT-3 论文）：足够大的语言模型只要在提示里给几个例子就能完成新任务、不用再训练，这是“用提示词编程”的基础。
- 关系：相近
- 复核理由：给好的参考样例让模型照着做，依赖的就是上下文里的少样本学习能力。

**2. 论文从闭源模型里偷出隐藏思维链**
- 源知识：混淆代理人问题：一个手握权限、替别人办事的程序（代理人），被权限更低的一方骗着去动用自己的权限，做了请求者本来做不了的事；是权限提升的一种，常被用来说明为什么需要基于能力的安全设计。
- 关系：相近
- 复核理由：攻击者借小模型手里的解密权限做了自己做不到的事，结构上就是混淆代理人。

**3. 中小機構 2026 AI 利用调查：88% 的中小企业没有专门部门，AI/IT 都靠经营者和现场自己推；最缺同行案例（83.3% 说不够）**
- 源知识：创新扩散理论：新技术通过沟通渠道在社会系统中逐步扩散，采用者依次是创新者、早期采用者、早期大众、后期大众和落后者。
- 关系：相近
- 复核理由：缺案例、缺试用，对应罗杰斯说的可观察性和可试用性

**4. 用 AI 数字人教练做运动训练产品**
- 源知识：规模经济：产量越大，单位成本越低。
- 关系：相近
- 复核理由：拍摄动作库是一笔固定成本，只有规模大的公司摊得开；AI 压低这笔成本就削弱了规模门槛，和规模经济相关。

**5. OpenAI 报告：用户最常用的是懒脑力活**
- 源知识：认知吝啬者：人处理信息的能力有限，所以不论多聪明，都会尽量走捷径、少花脑力。
- 关系：相近
- 复核理由：高学历人群也用 AI 省脑子，正对应认知吝啬者说的不论多聪明都少花脑力。

**6. OpenAI 称九成潜在市场来自企业**
- 源知识：颠覆式创新：在位企业的产品性能超过多数客户需要时，新进入者用更简单、更便宜、“够用”的产品从低端或新市场切入，最后取代在位者。
- 关系：相近
- 复核理由：企业不需要最强性能、要够用又便宜的产品，和性能过度满足后低端产品胜出的思路相近。

**7. 潜入 Cursor 60 天看到的公司文化**
- 源知识：建设性冲突：冲突就是差异，不分好坏；与其压下去，不如像工程师利用摩擦那样让它干活，用“整合”找到双方都满足的方案，而不是一方压倒或各让一步。
- 关系：相近
- 复核理由：相互挑刺打磨产品和把冲突用起来很像，但没有体现 Follett 的整合方案，不是同一理论换个名字。

**8. 大阪府各区划与公立小学教育概况**
- 源知识：蒂伯特模型（用脚投票）：居民会搬到税负和公共服务组合最合自己心意的地方，地方政府之间因此形成竞争。
- 关系：相近
- 复核理由：家庭按学校质量选住处、形成居住分层，是用脚投票的典型表现。

**9. Manus 本质是缝合怪但体验做得漂亮**
- 源知识：构建高效的智能体：把大模型系统分成「工作流」（代码预设路径）和「智能体」（模型自己决定过程和工具使用），列出增强型 LLM 和五种工作流模式，主张从最简单方案起步、显式展示规划步骤、精心设计工具接口。
- 关系：相近
- 复核理由：Manus 用大模型调度现成的 agent 和工作流，确实和该文的编排者-执行者模式很像，作者自己没提，算相近。

**10. 蔡崇信访谈：与马云初见的故事**
- 源知识：心理安全感：团队成员相信提想法、提问题、说担忧或承认错误不会被惩罚或羞辱；有了它，团队才会互相学习、敢于尝试和创新。
- 关系：相近
- 复核理由：领导带头认错、不装最聪明，以免扼杀创新，和心理安全感说的敢认错团队才会创新是同一个道理
