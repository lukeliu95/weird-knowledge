# 20个真实事件：知识库是否改善判断

> 2026-11-24。已授权“用20个真实事件测试一下”。本次只做离线对照，不改现有判断入口、模型默认或已确认原则。

## 要回答的问题

给同一个模型相同的公开事件材料，额外提供知识库里的基础知识，是否能让结论更准确、解释更有依据？本轮测基于材料的判断，不测未来预测，不把“能引用理论”当成判断正确。

## 事先固定的方法

- 20个真实、可回查的一手事件，覆盖工程故障、产品与商业实验、科研。题目中的待判断主张由本次测试编写，不能冒充原作者原话。
- 排除知识库已经直接保存过结果的同一事件；检查原始URL、论文名和案例关键词。历史事件可能已在模型训练中出现，这一限制不能排除。
- 两组看同一份事件事实。直接组不看知识库；查库组只额外看从冻结的`roots/`中检索的相关定义与边界，不提供新知识反向链接、整理结论或私人资料。
- 根据题目与事实检索，不使用标准答案或评分要求检索。测试前冻结20题、标准答案、材料与检索结果，记录哈希；看到成绩后不换题、不改提示词、不挑运行。
- 使用项目当前决定判断模型`claude-opus-5-5`、相同推理强度、独立无工具会话。每组各跑两次，共80份判断；打乱题序并记录全部失败、重试、原始结果和用量。
- 主指标：三类判断“材料支持／材料反驳／材料不足”的正确数，以及概率的Brier分数（越低越好）。按事件配对比较，两次重跑不当成40个独立事件。
- 次指标：独立审查时隐藏组别，检查是否抓到关键事实、保留适用范围、提出可验证的下一步。该部分是模型评审，只作辅助，不代替客观答案。
- 标准答案先由第二位agent核对出处和歧义；代码由未编写代码的agent审查。两次运行之间不改方法。结果接近或出现满分时，照实报告，没有差异也算测试完成。
- 只使用现有Claude Code订阅，不新增收费接口。预计模型调用约20～30次（按批处理80份判断和准备检索）；实际调用、输入输出token及耗时在报告里核对，订阅工具显示的API折算价不当成额外账单。
