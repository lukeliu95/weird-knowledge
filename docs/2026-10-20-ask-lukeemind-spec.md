# 问 lukeeMind：让别的 agent 先问"Luke 会怎么选"

> 2026-10-20 · Luke 审过：先做命令行，放权门槛"某一类满 30 次、一致率 90%、零漏报"。第一版已做好，规则见 AGENTS.md v1.15「流程七」
> 起因：Luke 选了 A：先做一个"问 lukeeMind"入口，接到 Codex 里的接待 Lukee 上，只给建议，不替他执行。他同意这个项目从这一步开始接触工作上的决定，工作数据只放 `private/`
> 名字：本项目的 agent 叫 **lukeeMind**（大脑）；Codex 里负责接待飞书消息、分派任务的叫 **Lukee**（接待和路由）

## 一、先说结论

| 问题 | 回答 |
|---|---|
| 做什么 | 一个命令：别的 agent 交来"问题、选项、背景"，lukeeMind 回"Luke 多半选哪个、有多确定、依据是什么、这件事要不要必须交给 Luke" |
| 谁用 | 先给 Codex 的 Lukee 用，之后各项目里的 Claude Code 和 Codex 都能用 |
| 现在能放多少权 | 一开始只给建议，所有决定仍由 Luke 点头。每次都记下"lukeeMind 的建议"和"Luke 的实际选择"，一致率够了再按级放权 |
| Codex 那边要做什么 | 规则里加一段"什么时候问、问完怎么用、Luke 答了以后回填结果"，并允许它执行这条命令。规则只能由 Luke 让 Codex 自己改，第九节有可以直接粘贴的文字 |

## 二、客户是谁，为什么在意

- **客户**：Luke，和替他干活的各个 agent
- **他在意什么**：agent 越来越多，遇到"选 A 还是选 B"都停下来问他，他成了所有 agent 共同的瓶颈（原则 6）
- **能给他什么**：agent 先拿到一个"Luke 多半会这么选"的建议。他看到建议只要回"按 lukeeMind 的"；放权级别升上去以后，低风险的事就不用再问他

## 四、接口

第一版是命令行，Codex 和 Claude Code 都能直接调。等用顺了，再包一层 MCP，让它在 Codex 里显示成一个工具。

**问**

```bash
python3 /Users/lukeliu/claude/duzhe/tools/mind/ask.py \
  --from codex-lukee \
  --question "客户要求下周三前上线，要不要答应？" \
  --options "A:答应，加班赶|B:说明风险，改到下下周|C:先上一个精简版" \
  --context-file /tmp/ctx.md
```

- `--options` 可以不给：lukeeMind 会先列出它看到的几个做法，再给建议
- `--context-file`：这件事的背景（谁问的、前面聊了什么、相关约束），Lukee 自己整理，不放密钥和账号

**回**（JSON）

| 字段 | 意思 |
|---|---|
| `id` | 这次提问的编号，回填时用 |
| `choice` | 多半选哪个 |
| `probs` | 每个选项的概率 |
| `confidence` | 高 / 中 / 低 |
| `evidence` | 依据：哪几条原则、哪几次相似的旧选择（一句话说清） |
| `must_ask_luke` | 是否必须交给 Luke，以及原因 |
| `note` | 给 Luke 看的一句话建议，用他的口气 |

**回填**

```bash
python3 /Users/lukeliu/claude/duzhe/tools/mind/ask.py record <id> --luke B --note "Luke 原话"
```

## 六、怎么证明它靠得住

| 指标 | 意思 | 怎么用 |
|---|---|---|
| 一致率 | 回填了的决定里，lukeeMind 的建议和 Luke 的实际选择一样的比例 | 按事情的类别分开算 |
| 偏离推荐时的命中 | Lukee 自己有推荐、Luke 却没按推荐走的那些，lukeeMind 猜中几次 | 这才是真本事 |
| 漏报 | 本该交给 Luke、却判成不用问的次数 | 一次都不许有，有一次就整体降一级 |

**放权阶梯**（原则 12：按后果分级、靠证据升级）

| 级别 | lukeeMind 的建议怎么用 | 升级条件 |
|---|---|---|
| 0 级（起步） | 只给建议。Lukee 照旧问 Luke，把建议附上 | 某类事回填满 30 次，一致率 90% 以上，没有漏报 |
| 1 级 | 这一类、并且 `confidence` 为高的，Lukee 可以按建议直接做，每天汇总给 Luke | 1 级跑满两周，一次都没被 Luke 推翻 |
| 2 级 | 这一类全部按建议做，每周汇总 | 由 Luke 决定 |

- 每一次升级都要 Luke 点头，lukeeMind 只负责报数字、提建议
- 出一次错（被 Luke 推翻且后果不小，或者出现漏报），这一类马上降一级
- "必须交给 Luke"清单里的事，永远停在 0 级

## 七、数据和隐私

- 工作上的提问、背景、Luke 的回填，只存 `private/mind/`（本机、没有远端、不进公开仓库）
- 背景只交给 Opus（Luke 已同意它看私人资料），不交给 Jev，不交给任何外部接口
- 不同客户的背景不混用：判断时只取同一客户或不涉及客户的旧选择做例子
- lukeeMind 的建议不冒充 Luke 的决定，交给同事和客户的话仍由 Lukee 按它自己的规则写

## 九、Codex 那边要做什么

lukeeMind 这边做好后，Codex 的 Lukee 要做 5 件事。它的规则只听 Luke 的，所以要 Luke 把下面这段交给它，让它自己改进它的规则文件：

5. **允许执行**：在 Codex 的权限里允许运行 `python3 /Users/lukeliu/claude/duzhe/tools/mind/ask.py`（它会调用本机的 `claude` 命令）
