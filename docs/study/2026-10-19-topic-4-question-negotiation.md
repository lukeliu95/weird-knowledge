## 一、现在的答案

1. **理论根很深**："问题协商"是一条 50 多年的研究线。Taylor 1968 说用户开口问的是妥协过的问题；Belkin 1982 说需求本来就说不准，并设计了"给结果、说明为什么选它、问用户反馈"的检索循环，和 Luke 方案的循环几乎一样；Dervin 1986 给出可照着问的三类问题：情境、缺口、用途；Slovic 1995 说人对陌生的选择没有现成偏好，偏好是在被问的过程中才拼出来的。
2. **"先给样本"有证据**：找房实验里，加上"提示样本"后决策准确率从 45% 升到 80%；聊天咨询里，最能预测满意度的是收尾问"回答完整了吗"，追问本身没有显著作用；只在有把握时追问，比总是问和从不问都好。
3. **怎么问有讲究**：具体的问题比万能问题好得多；把选项包装成一句具体的问题，比只写"请选一个"点击率高约一半；第一个问题最决定用户愿不愿意配合。不能让大模型自己决定该问什么，它判断"要不要问"接近瞎猜。
4. **样本怎么挑**：不能只给最像的（会把用户锚死），也不能只图分散；最好混入"用户只要再加一个条件，它就会变成最好"的样本。一批样本要彼此不同。
5. **"未知"要单独一档**：把查不到当成"不是"，是在知识有空白的地方误用了封闭世界假设；企业不公开某项数据，往往本身就带信息；用户没点过的企业是"没判断"，不是"不要"。

## 三、对 Luke 方案的意义（推断，要他判断）

**已经对上的**

- 先给样本、再协商：Belkin 的 ASK 循环、Kwon 的"先给实在的东西"、Zhang & Choi 的"有主流意思就直接做"都支持
- 符合、不符合、未知三档：封闭世界假设、缺失数据机制、PU 学习三条理论都支持
- 退回去问主题、为什么、背景：对应 Taylor 的过滤器和 Dervin 的情境、缺口、用途
- 样本混着挑：Viappiani 的提示样本和 Settles 的"一批要彼此不同"都支持
- 用行为指标（查清几家、要了几家、花多少）而不是满意度来判断：Dewdney 的实验显示满意度有天花板

**可以补上的**

1. **每家样本附一句"为什么选它"**：Belkin 的循环比方案多这一步
2. **收尾问一句"这批是不是你要的"**：这是 Kwon 研究里最强的满意度预测因素
3. **三条路上面配一句具体的问题**，而不是"请选择"：必应的大规模实验支持
4. **协商的维度事先定成清单，模型只从清单里挑**：大模型自由决定问什么不可靠
5. **第一轮样本和第一个问题要格外准**：用户对第一个追问反应最大
6. **保留"都不对，我重新想"**：给选项会把开放问题变成封闭问题（Ross 等的担心，有争议）

## 六、查出来的误传

| 常见说法 | 实际 |
|---|---|
| "只有 55% 的读者满意" | 是暗访者问短的事实题时的答对率，作者那次实测 62%，55% 是多项研究合起来的整数 |
| "问一个澄清问题效果提高 170%" | 事后挑最好问题的理想上限，论文里还有好几种写法；真实模型约 +34%～45% |
| "必应的澄清让满意度提高 48%" | 量的是点击率；对照组也有同样的选项 |
| "举例批评提升 78%" | 20 名学生找房的相对提升（45% → 80%） |
| "低质量的澄清问题不伤体验" | 只来自 5 人访谈，被 89 人的对照实验推翻 |
| "追问越多越好" | 聊天咨询里追问本身和满意度无关 |
| "偏好是建构的，所以人没有偏好" | 只针对复杂、陌生的决策，熟悉的环境里偏好会稳定 |
| "MCAR / MAR / MNAR 都是 Rubin 1976 提出的" | Rubin 1976 没提 MCAR |
| "封闭世界假设是错的" | 信息完整时它是对的，问题在知识有空白时误用 |
| "用线索评分投资回报高 70%" | 来自厂商指南，不是独立研究 |
