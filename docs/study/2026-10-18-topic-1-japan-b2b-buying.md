## 一、现在的答案

1. **谁拍板**：多人一起定。大企业形式上是社长盖最后一个章，实际是课长级的起案人写稟議书，并且事先一个个说服相关部门（根回し）。中小企业约八成的老板会参与，约三成亲自主导。约一半的购买有 5 人以上参与。
2. **流程多长**：就算有预算，上市公司里约八成花钱前还要再走一次稟議，约一半的购买要 1 个月以上。最难的一步是向公司内部说明费用效果。
3. **怎么选**：买家先自己在网上查，接触卖方时 63.5% 已经列好了候选，八成只比 3 家以内。日本懂 IT 的人 73.6% 在供应商那边，客户又怕担责，所以容易选大厂、选老供应商。
4. **冷邮件合不合法**：给企业官网公开的邮箱发 B2B 广告，法律有明文例外，但每封要写清发送者和退订方法，对方一拒绝就要停。表单营销算不算邮件，官方没有结论。
5. **回信率**：日本没有可靠的公开数据，只有厂商自报：代打电话每通约 3.8% 能约到，表单营销点击率约 4～7%，海外冷邮件回信率约 3.4%。决定对方回不回的是"和我有没有关系"：73% 的买家会主动回避不相关的推销。

背后的理论有五十年了：[采购中心](../../roots/buying-center.md)（1967 / 1972）说企业采购是一群角色不同的人一起定；[谢斯模型](../../clips/2026-10-18-sheth-industrial-buyer-behavior.md)（1973）说风险越高越要多人定，人一多，冲突怎么解决决定了快慢；[企业行为理论](../../roots/behavioral-theory-of-the-firm.md)（1963）说每个人都想降低自己的风险，所以天然偏向维持现状。稟議和根回し是这套规律在日本的制度化形态。

## 三、对你工作的意义（都是推断，要你判断）

1. **冷触达的目标是进入那 3 家候选，不是一封邮件就约到会。** 收件人多半还在自己做功课的前半段，邮件要让他愿意把你放进清单，并且方便转给公司里的其他人看。
2. **第一封信写给起案人。** 给他能直接贴进稟議书的东西：大致价格、同行业的导入案例、费用效果怎么算、机密信息怎么处理。这四样分别对上了"最先想知道价格""导入案例最可信""最难说明费用效果""最怕泄密"。
3. **大企业和中小企业用两套打法。** 大企业找课长级的起案人，同时准备给 IT 和信息安全部门看的材料；中小企业直接找社长，讲业绩和人手，不讲技术。
4. **新供应商先要回答"选你会不会被追责"。** 知名客户、导入案例，以及和客户原有 SIer 或代理的合作，比功能对比更能降低客户的风险感。
5. **合规底线（不是法律意见）**：只发给官网公开的公司邮箱或交换过名片的人；发之前查对方页面有没有"営業メールお断り"；每封写明正式公司名、住所、退订方法；拒绝过的永久剔除。表单营销也按这个标准做。
6. **最可靠的回信率是你们自己的。** 公开的数字都是厂商自报，口径各不一样。

## 六、查出来的误传

| 常见说法 | 实际 |
|---|---|
| "57% 的买家联系销售前已经做好决定" | 57% 是购买进度的平均值，不是买家的比例，也不是"已经决定"（[CEB 2012](../../clips/2026-10-18-ceb-digital-evolution-b2b-marketing.md)） |
| "冷电话成功率只有 0.3%" | 出自 B2C 房产经纪人随机拨打住户的小研究，作者本人结论偏正面（[贝勒大学 2012](../../clips/2026-10-18-lampertz-has-cold-calling-gone-cold.md)） |
| "违反特電法直接罚 3,000 万" | 先整改命令，不服从才罚；3,000 万是法人罚金上限（[特電法](../../clips/2026-10-18-japan-specified-email-act.md)） |
| "官方说表单营销不受特電法管" | 没有任何官方说法 |
| "名片上的联系人不能拿来发广告" | 2005 年旧法时期的说法；现行 Q&A 4-16 明确说可以 |
| "表单营销回信率一般 3～7%" | 查不到出处，原文自相矛盾 |
| "日本是自下而上决策，权力在基层" | Vogel 1975 明确反驳 |
| "日本不确定性规避全世界最高""日本是典型集体主义" | 92 分，希腊、葡萄牙更高；个人主义 46 分在中间，复查 35 项研究只有 5 项支持集体主义的说法 |
| "2025 年日本会损失 12 兆日元" | 原文是"2025 年以后每年最多可能"，而且是粗略推算 |
| "采购中心有六种角色" | 1972 年原文只有五种，没有"发起者" |
