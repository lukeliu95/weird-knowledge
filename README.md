# 奇怪的知识又多起来了

一个阅读助手 agent。它存在的意义，就是让你每天都能真心实意地说出这句话。

> 新知识是叶子，源知识是根，框架是你自己长出来的树。施肥靠你每天刷手机。

Claude Code 和 Codex 都能用。规则只有一个文件：[AGENTS.md](AGENTS.md)。

曾用名：读者（duzhe）。改名原因："读者"太正经了，配不上库里那条南明冷知识。

## 为什么做这个

你一定有过这种经历：在 X 上刷到一条"颠覆认知的新方法"，点赞、收藏、转发一条龙，然后这辈子再也没打开过。

更扎心的是，往下查一查就会发现，很多"新方法"其实是几十年前的老理论，换了身衣服重新出道。

所以与其收藏一堆马甲，不如直接去找本尊：

- 每条新内容，都追到它背后的理论、方法论、论文或研究报告
- 统计哪些理论被反复指向。被指向得越多，越接近本质
- 把这些本质提炼成几条你自己相信的原则，每条都能指回出处

## 它做三件事

| 做什么 | 你说 | 结果放在 |
|---|---|---|
| 存 | "存一下"，加上原文、链接或截图 | `clips/`，一条一个文件，原文一字不改 |
| 溯源（俗称扒马甲） | "整理" | 每条内容下面写上它的源头，源头理论存进 `roots/` |
| 维护框架 | 整理时一起做 | `framework.md`：你的原则、知识底座、待查清单 |

每存完一条，它都会说一句"奇怪的知识又多起来了（第 N 条）"。这是它唯一的情绪表达。

没整理的内容攒满 10 条，它会提醒你整理。

举个例子：库里最早存的几条里，有一条是"南明的皇太后受过洗，教名海伦娜"。目前还没看出它有什么用，但不可否认，奇怪的知识确实又多起来了。

## 一条内容会经历什么

```
你发来一条推文 / 长文 / 截图
   │  存：抓原文，问你为什么存
   ▼
clips/        新知识（原文不改）
   │  整理：剥掉包装 → 找源头 → 判关系 → 往上追 2～3 层
   ▼
roots/        源知识（一个理论一个文件，必须联网查到出处）
   │  数一数每个理论被几条新知识指向
   ▼
framework.md  你的思考框架（模型写的是草稿，你确认后才算数）
```

溯源时，新知识和源知识的关系分五种：

| 关系 | 意思 |
|---|---|
| 直接源自 | 作者明说了出处，是个老实人 |
| 换了说法 | 老理论换了个新名词，重新出道 |
| 相近 | 作者自己想出来的，结果和前人撞车了 |
| 挑战 | 和经典理论对着干。要么是真的新东西，要么是错的，都值得多看两眼 |
| 没找到源头 | 查不到，标"待查"。可能是真的新东西，也可能是查得还不够 |

## 怎么用

### 需要什么

| 东西 | 用来做什么 | 必须吗 |
|---|---|---|
| [Claude Code](https://claude.com/claude-code) 或 [Codex](https://github.com/openai/codex) | 运行这个 agent | 二选一 |
| [opencli](https://github.com/jackwener/opencli) | 抓 X 的推文和长文，查维基百科和论文 | 不必须。没有的话，把原文直接贴给它就行 |
| git | 记录每次存和整理，以后能回看想法是怎么变的 | 建议有。毕竟"我以前居然信过这个"，也是一种奇怪的知识 |

### 开始

1. fork 或 clone 这个仓库
2. 清空成你自己的库（别人的奇怪知识，终究是别人的）：
   - 删掉 `clips/`、`roots/`、`docs/reviews/` 里的文件，保留 `.gitkeep`
   - 用下面这条命令把 `framework.md` 恢复成空模板
   - 把 `AGENTS.md` 里的"Luke"换成你的名字

   ```bash
   git checkout f2acee2 -- framework.md
   ```

3. 在这个文件夹里打开 Claude Code 或 Codex。它会自动读到 `AGENTS.md`，知道自己是"奇怪的知识又多起来了"
4. 发一条内容给它，说"存一下"
5. 攒够了，说"整理"

### 改规则

规则全部写在 [AGENTS.md](AGENTS.md)。`CLAUDE.md` 只有一行，负责让 Claude Code 引入它。

用的时候直接纠正它就行，比如"以后串推只存第一条"。它会把你的话提炼成通用规则写进 `AGENTS.md`，再单独提交一次。挨了骂会写检讨，而且是能直接执行的那种。

## 目录

```
weird-knowledge/
├── AGENTS.md        agent 的全部规则（Claude Code 和 Codex 共用）
├── CLAUDE.md        一行：引入 AGENTS.md
├── clips/           新知识，一条一个文件，如 2026-10-18-author-short-title.md
├── roots/           源知识，一个理论一个文件，如 galls-law.md
├── framework.md     思考框架
└── docs/
    ├── 2026-10-18-plan.md    最初的方案
    └── reviews/              每轮整理的记录
```

## 怎么防止编造

模型最擅长的事情之一，就是一本正经地编出一篇不存在的论文。所以这里的规矩比较多：

- 每个源理论都要联网查到原始出处（论文、书、作者本人的文章），附上链接。查不到就标"待确认"，不许脑补
- 谁最先提出有争议时，写明有争议，不替历史做决定
- 关联分强弱：有证据的算"强"，模型推断的算"弱"，要人确认
- 原文一字不改，分析写在原文下面
- 框架里的原则，模型写的都只是草稿。你点头之前，它说了不算
