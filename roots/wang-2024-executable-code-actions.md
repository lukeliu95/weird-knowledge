# CodeAct：用可执行代码当智能体的动作（Executable Code Actions Elicit Better LLM Agents）

## 一句话

让大模型智能体直接写可执行的 Python 代码作为动作（CodeAct），而不是输出固定格式的 JSON 或文本工具调用；代码能组合多个工具、用上现成的软件包，并根据执行结果多轮修正，成功率更高。
