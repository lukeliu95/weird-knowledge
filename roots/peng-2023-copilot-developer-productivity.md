# AI 对开发者生产率的影响：GitHub Copilot 对照实验（The Impact of AI on Developer Productivity: Evidence from GitHub Copilot）

## 一句话

对照实验：用 GitHub Copilot 的开发者写一个 JavaScript HTTP 服务器，比对照组快 55.8%；编程经验少的人受益更多。

## 原始出处

- The Impact of AI on Developer Productivity: Evidence from GitHub Copilot, Peng et al., arXiv 2302.06590, 2023，https://arxiv.org/abs/2302.06590
- Research: quantifying GitHub Copilot's impact on developer productivity and happiness, GitHub Blog, 2022（55% 的数字最早在这里发布），https://github.blog/research/research-quantifying-github-copilots-impact-on-developer-productivity-and-happiness/
- 争议：55% 这个数字 GitHub 2022 年先在博客发布，2023 年写成论文；实验只测了一个编程任务。
