# RFC 2119 要求等级关键词（RFC 2119: Key words for use in RFCs to Indicate Requirement Levels）

## 一句话

规定技术规范里用 MUST（必须）、SHOULD（应该，有正当理由可例外）、MAY（可以）等词来区分要求的强弱。
