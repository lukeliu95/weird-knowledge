# 多任务学习（Multi-task learning）

## 一句话

几个相关任务用共享的表示一起学，彼此的训练信号互相当归纳偏置，泛化更好；任务要求冲突时会互相拖累（负迁移）。

## 原始出处

- Multitask Learning, Rich Caruana, Machine Learning, 1997，https://doi.org/10.1023/A:1007379606734
- Multi-task learning, Wikipedia，https://en.wikipedia.org/wiki/Multi-task_learning
- 争议：Caruana 1997 是被引最多的系统论述，但更早已有叫“提示”（hints）的做法（Abu-Mostafa 1990 等）。
