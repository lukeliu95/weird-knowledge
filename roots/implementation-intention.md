# 执行意图（如果-那么计划）（Implementation intention）

## 一句话

在目标之外再定好“在什么时候、什么地方、遇到什么情况就怎么做”，能明显提高执行率。

## 原始出处

- Implementation intentions: Strong effects of simple plans，Gollwitzer，American Psychologist 54(7)，1999，https://doi.org/10.1037/0003-066X.54.7.493
- Implementation intention，英文维基百科，https://en.wikipedia.org/wiki/Implementation_intention
