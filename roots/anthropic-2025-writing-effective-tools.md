# 为智能体写好用的工具（并借助智能体来写）（Writing effective tools for agents — with agents）

## 一句话

工具要为智能体重新设计，而不是把现有软件功能或 API 原样包一层；工具不是越多越好，要少而精；描述要像写给新同事一样把隐含背景说清，参数命名无歧义，只返回高信号信息并支持分页、过滤和截断；再用评测让智能体帮忙改进工具。
