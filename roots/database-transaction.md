# 数据库事务（Database transaction）

## 一句话

把一组操作当成一个整体：要么全做、要么全不做，出错或断电也保持数据一致；常用 ACID（原子性、一致性、隔离性、持久性）概括。

## 原始出处

- Wikipedia: Database transaction，https://en.wikipedia.org/wiki/Database_transaction
- The Transaction Concept: Virtues and Limitations, Jim Gray, VLDB, 1981，https://openalex.org/W1563849906
- Wikipedia: ACID（缩写由 Härder 与 Reuter 1983 提出），https://en.wikipedia.org/wiki/ACID
- 争议：Gray 1981 年阐述事务概念时提出了原子性、一致性、持久性三项；ACID 缩写（加上隔离性）由 Härder 和 Reuter 1983 年提出。
