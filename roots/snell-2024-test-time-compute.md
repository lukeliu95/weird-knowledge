# 测试时算力的最优扩展（Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters）

推理时多花算力（用验证器搜索、按题目难度分配算力），在同等计算量下，小模型可以胜过大 14 倍的模型。
