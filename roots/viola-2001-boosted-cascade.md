# 级联分类器（Viola–Jones 快速目标检测）（Rapid Object Detection using a Boosted Cascade of Simple Features）

## 一句话

把越来越复杂的分类器串成一条"级联"：前几级又快又便宜，先把明显不是目标的大量背景区域扔掉，只有可疑的区域才交给后面更费算力的分类器，从而做到实时人脸检测。
