# Chow 拒识规则：识别错误率与拒识率的最优权衡（On optimum recognition error and reject tradeoff）

## 一句话

分类时允许“拒绝判断”：当最有可能的类别的后验概率低于某个门槛就不判、交给别的处理；门槛越高，错误越少但拒得越多，最优门槛由错判和拒判各自的代价决定。

## 原始出处

- On optimum recognition error and reject tradeoff, C. K. Chow, IEEE Transactions on Information Theory 16(1): 41–46, 1970，https://doi.org/10.1109/TIT.1970.1054406
- An optimum character recognition system using decision functions, C. K. Chow, IRE Transactions on Electronic Computers EC-6(4): 247–254, 1957，https://doi.org/10.1109/TEC.1957.5222035
- 争议：常被称为“Chow 规则”的拒识规则，有文献说 1957 年那篇字符识别论文已首次引入拒识（如 VisionBib 书目注释），1970 年这篇系统分析了错误与拒识的权衡；1957 年原文的扫描版难以辨认，首提年份待确认。
