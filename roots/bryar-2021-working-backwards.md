# 亚马逊可控投入型指标（出自《Working Backwards》）（Working Backwards: Insights, Stories, and Secrets from Inside Amazon）

## 一句话

亚马逊把指标分成“可控投入型指标”（选品、有货率等自己能直接推动的）和“产出型指标”（营收、股价等），管理层在每周业务回顾里盯前者，因为产出没法直接控制；选对投入指标要反复试错。

## 原始出处

- Working Backwards, Colin Bryar & Bill Carr, St. Martin's Press, 2021（作者官网），https://workingbackwards.com/
- How Amazon Uses Input Metrics, Huy Nguyen, Holistics, 2021-02-24（摘引原书），https://www.holistics.io/blog/how-amazon-uses-input-metrics/
- 争议：这套分法在亚马逊内部用了很多年，书在 2021 年才系统写出来；业界一般把它叫领先/滞后指标。
