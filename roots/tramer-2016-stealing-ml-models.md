# 通过预测 API 窃取机器学习模型（模型窃取攻击）（Stealing Machine Learning Models via Prediction APIs）

## 一句话

只要能按次调用一个对外开放的模型接口，攻击者就能靠大量提问和收集回答，复制出功能几乎一样的模型；模型保密和公开访问之间天然有张力。
