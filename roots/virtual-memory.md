# 虚拟内存（Virtual memory）

## 一句话

用分页等技术把小而快的主存和大而慢的外存组合起来，让程序以为自己有一块很大的内存。

## 原始出处

- Wikipedia: Virtual memory，https://en.wikipedia.org/wiki/Virtual_memory
- 争议：有说法称 Fritz-Rudolf Güntsch 1956 年博士论文首创，维基认为经不起推敲（更像缓存）；Robert S. Barton 1958 年也提出过自动分配主存。
