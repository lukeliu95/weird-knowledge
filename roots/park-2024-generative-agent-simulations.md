# 生成式 agent 模拟 1,000 个真人（个人模拟）（Generative Agent Simulations of 1,000 People（第 3 版改名 LLM Agents Grounded in Self-Reports Enable General-Purpose Simulation of Individuals））

## 一句话

用 1,052 个美国人的 2 小时访谈（或问卷）给每人建一个大模型 agent，预测本人没答过的社会调查题，准确率达到本人隔两周重答一致性的 83%～86%（第 1 版写 85%），只给人口统计信息的 agent 只有 74%。
