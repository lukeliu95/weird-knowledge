# 《人只需要富一次》（You Only Have to Get Rich Once）

## 一句话

华尔街分析师 Gutman 的书，巴菲特评价它“书很烂但书名很棒”，用书名说明富了以后最重要的是别再变穷。

## 原始出处

- Walter K. Gutman 讣告（Bowdoin College），列出其 1961 年著作 You Only Have to Get Rich Once，https://obituaries.bowdoin.edu/?p=1112
- 巴菲特 1998 年佛罗里达大学演讲讲稿中引用该书，https://svcaf.org/files/buffett-uf-lecture-1998.pdf
