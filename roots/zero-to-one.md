# 从 0 到 1（Zero to One: Notes on Startups, or How to Build the Future）

## 一句话

进步来自从 0 到 1 的全新创造而不是模仿；创业要追求垄断、避开完全竞争，从小市场做起，靠专有技术、网络效应、规模经济和品牌建立长期优势。
