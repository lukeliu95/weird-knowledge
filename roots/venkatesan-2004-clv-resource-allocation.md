# 用客户终身价值选客户、分配营销接触（A Customer Lifetime Value Framework for Customer Selection and Resource Allocation Strategy）

## 一句话

按客户终身价值挑客户、在各渠道之间分配营销接触；各渠道的接触对终身价值的影响不是线性的，按终身价值选出的客户未来利润更高。
