# BadNets：机器学习模型供应链里的后门（BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply Chain）

## 一句话

外包训练或下载的现成模型可能被做了手脚：平时表现完全正常，一见到攻击者设定的触发图案（比如停车牌上贴张小贴纸）就做出指定的错误判断，而且很难察觉。
