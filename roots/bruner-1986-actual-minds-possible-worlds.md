# 《真实的心灵，可能的世界》（范式思维与叙事思维）（Actual Minds, Possible Worlds）

## 一句话

布鲁纳认为人有两种不能互相替代的思维方式：追求真假、讲因果和逻辑的“范式（逻辑—科学）模式”，和追求逼真、讲意图和意义的“叙事模式”；论证让人相信它是真的，故事让人相信它像真的。
