# 生成对抗网络（Generative adversarial network (GAN)）

## 一句话

一个网络负责生成，另一个网络负责判断真假，两者对抗、互相逼着变强，生成者最后学会做出以假乱真的结果。

## 原始出处

- Generative adversarial network（维基百科），https://en.wikipedia.org/wiki/Generative_adversarial_network
- 争议：维基历史部分提到 Schmidhuber 1991 年的「人工好奇心」也是生成网络和预测网络的零和博弈，GAN 可看作它的一个特例；谁最先提出有不同看法。
