# 电报商用密码本（Commercial code (communications)）

## 一句话

电报按词收费，商家把成千上万个常用句子编成密码本公开出版，一个五个字母的词就代表一整句话；这些码本不为保密只为省钱，维基称之为一种数据压缩。
