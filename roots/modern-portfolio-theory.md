# 现代投资组合理论（均值-方差分析）（Modern portfolio theory (mean-variance analysis)）

## 一句话

做选择要同时看期望回报和风险（方差），在给定风险下追求最高回报；分散能消掉各自独有的风险，但所有选项共担的系统性风险分散不掉。

## 原始出处

- Markowitz, Portfolio Selection, Journal of Finance 7(1): 77–91, 1952，https://doi.org/10.1111/j.1540-6261.1952.tb01525.x
- Modern portfolio theory（维基百科），https://en.wikipedia.org/wiki/Modern_portfolio_theory
- 争议：A. D. Roy 同年（1952）独立发表了“安全第一”的类似框架；de Finetti 1940 年在保险问题里已用过均值-方差思路。“系统性风险分散不掉”的定价含义是后来 Sharpe 1964 等的 CAPM 讲清楚的。
