# 剩余价值（Surplus value）

## 一句话

工人创造的新价值超过自己工资的那一部分，被资本家作为利润拿走；马克思用它解释资本主义下剥削从哪里来。

## 原始出处

- Surplus value，英文维基百科，https://en.wikipedia.org/wiki/Surplus_value
- 争议：概念出自李嘉图派社会主义者，William Thompson 1824 年最先用了“surplus value”一词，马克思用的是德文 Mehrwert；有史学家认为马克思大量借鉴了 Thompson，优先权有争议。
