# 隐藏议程用户模拟（The Hidden Agenda User Simulation Model）

## 一句话

把模拟用户的状态写成“目标 + 议程栈”：议程是用户还没说出口的对话动作，系统每说一句，用户按压栈、出栈决定下一句；隐藏状态可以用 EM 算法从少量标注的真实语料里学出来。
