# 货币的时间价值（Time value of money）

## 一句话

今天的一块钱比将来的一块钱更值钱，因为它可以拿去投资生息。

## 原始出处

- Time value of money, Wikipedia，https://en.wikipedia.org/wiki/Time_value_of_money
- 争议：有人把 16 世纪的 Martín de Azpilcueta 视为先驱，但专业学者提醒不宜把他当作现代时间偏好理论的最早表述。
