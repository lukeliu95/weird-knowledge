# 混合主导用户界面的原则（Principles of Mixed-Initiative User Interfaces）

## 一句话

让自动化的 agent 和用户的直接操作配合，共 12 条原则：考虑对用户目标的不确定，按期望价值决定何时行动，拿不准时用对话澄清，允许用户随时调用、终止和修正，表现得像善意的助手，记住近期交互，并持续通过观察向用户学习。
