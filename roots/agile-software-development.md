# 敏捷软件开发（敏捷宣言）（Agile software development (Manifesto for Agile Software Development)）

## 一句话

四条价值观：个体和互动高于流程和工具，可用的软件高于详尽的文档，客户合作高于合同谈判，响应变化高于遵循计划。

## 原始出处

- Manifesto for Agile Software Development, 2001，https://agilemanifesto.org/
- Agile software development，英文维基百科，https://en.wikipedia.org/wiki/Agile_software_development
- 争议：宣言是 2001 年签署的，但其中的迭代、增量做法可追到 1950 年代（Larman 与 Basili 2003 年的梳理），不是 2001 年才发明。
