# 减少工作和信息过载的代理（Agents that Reduce Work and Information Overload）

## 一句话

直接操作界面要用户自己发起每项任务、盯住每个事件；应补上一种「间接管理」，由像私人助理一样的界面代理替用户发起和完成任务。
