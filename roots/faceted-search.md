# 分面搜索（Faceted search）

## 一句话

把条目的多个属性做成可点选的筛选维度，让用户边看结果边收窄。

## 原始出处

- Faceted metadata for image search and browsing，Yee 等，CHI '03: 401–408，https://doi.org/10.1145/642611.642681
- 分面分类的思想更早（图书馆学），最早出处待查
