# 软件设计模式（Software design pattern）

## 一句话

把软件里反复出现的问题和对应的可复用解法总结成有名字的模板；模式不是可直接复制的代码，而是解决一类问题的套路。

## 原始出处

- Software design pattern，英文维基百科，https://en.wikipedia.org/wiki/Software_design_pattern
- Design Patterns: Elements of Reusable Object-Oriented Software, Gamma, Helm, Johnson, Vlissides, 1994，https://en.wikipedia.org/wiki/Design_Patterns
- 争议：模式的概念来自建筑师 Christopher Alexander 1977 年的《A Pattern Language》；Beck 和 Cunningham 1987 年最先把它用到编程上，四人帮 1994 年的书让它成为主流。
