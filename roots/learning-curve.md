# 学习曲线（Learning curve）

## 一句话

一件事做的次数越多，熟练度越高、耗时越少。

## 原始出处

- Learning curve, Wikipedia，https://en.wikipedia.org/wiki/Learning_curve
- 争议：Ebbinghaus 1885 年最早描述，但“学习曲线”这个名称 1903 年才出现。
