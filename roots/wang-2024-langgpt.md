# LangGPT 结构化提示词框架（LangGPT: Rethinking Structured Reusable Prompt Design Framework for LLMs from the Programming Language）

## 一句话

借鉴编程语言的思路，把提示词拆成角色、简介、技能、规则、工作流、初始化等固定模块来写，便于复用和迭代。

## 原始出处

- LangGPT: Rethinking Structured Reusable Prompt Design Framework for LLMs from the Programming Language, Ming Wang et al., 2024, arXiv:2402.16929，https://arxiv.org/abs/2402.16929
- langgptai/LangGPT, GitHub（2023-05 建立），https://github.com/langgptai/LangGPT
- 争议：项目自称“结构化提示词提出者”，但 2023 年中文社区里分块写提示词的做法很普遍，谁最早提出有争议。
