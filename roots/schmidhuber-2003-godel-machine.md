# 哥德尔机：只做可证明有益的自我改写的通用求解器（Gödel Machines: Self-Referential Universal Problem Solvers Making Provably Optimal Self-Improvements）

## 一句话

一个能改写自己任何部分代码的求解器，但只有在找到“这次改写有用”的数学证明后才改，作者证明这样的改写是全局最优的；理论上严谨，实践中几乎无法证明大多数改动有益，后来的达尔文哥德尔机正是从这一点出发改成用基准实测。
