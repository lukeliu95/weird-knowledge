# AI 是 60 年来第一个新的界面范式（AI: First New UI Paradigm in 60 Years）

## 一句话

人机交互经历了批处理、命令式交互，AI 带来第三种「意图式结果指定」：用户只说想要什么结果，不说怎么做，步骤由 AI 自己想；控制权从人转到了机器。
