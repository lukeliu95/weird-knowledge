# Mario Zechner：也许你根本不需要 MCP（What if you don't need MCP at all?）

## 一句话

智能体本来就会跑 Bash、会写代码，而 Bash 和代码可以随意组合，所以多数场景直接调命令行工具就够，MCP 既占上下文又有安全隐患。
