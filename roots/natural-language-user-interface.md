# 自然语言界面（自然语言数据库接口）（Natural-language user interface (Natural language interfaces to databases)）

## 一句话

让用户直接用日常语言新建、查询和修改数据，不必懂查询语言和底层数据结构，由系统把话翻译成数据库操作。
