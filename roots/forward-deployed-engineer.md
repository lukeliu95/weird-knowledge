# 前线部署工程师（Forward deployed engineer (FDE)）

## 一句话

产品公司的软件工程师直接驻到客户那里，在自家平台上替客户实施和定制，交付业务结果。

## 原始出处

- Forward deployed engineer，英文维基百科，https://en.wikipedia.org/wiki/Forward_deployed_engineer
- Dev versus Delta: Demystifying engineering roles at Palantir，Palantir 官方博客，https://blog.palantir.com/dev-versus-delta-demystifying-engineering-roles-at-palantir-ad44c2a6e87
- 争议：Andreessen Horowitz 认为这个头衔有“头衔套利”成分，本质上是以前的解决方案工程师、集成工程师换了个名字；它和解决方案架构师、售前工程师、IT 顾问的职责有大量重叠。；名称来自美军术语，Palantir 约 2009 年起用作岗位名并让它流行；也有人（如 a16z）认为这只是给解决方案工程师、集成工程师换了个头衔。
