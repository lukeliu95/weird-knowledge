# 大型共享数据库的关系模型（A Relational Model of Data for Large Shared Data Banks）

## 一句话

用户不该被迫知道数据在机器里怎么组织；用只反映数据本身结构的“关系”（表）来描述数据，存储方式变了，应用和终端用户也不受影响。

## 原始出处

- A Relational Model of Data for Large Shared Data Banks，E. F. Codd，Communications of the ACM 13(6)，1970，https://doi.org/10.1145/362384.362685
- 论文 PDF（密歇根大学课程存档），https://web.eecs.umich.edu/~michjc/eecs584/Papers/codd_1970.pdf
- Relational model，英文维基百科，https://en.wikipedia.org/wiki/Relational_model
- 争议：维基称 Codd 1969 年已在 IBM 内部报告里首次描述关系模型，1970 年论文是正式发表。
