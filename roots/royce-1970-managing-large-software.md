# Royce 1970：大型软件系统开发管理（做两遍）（Managing the Development of Large Software Systems）

## 一句话

常被当作「瀑布模型」出处的论文，其实建议首次开发的系统要「做两遍」：先做试验性的版本，真正交付给客户的应是第二版。

## 原始出处

- Managing the Development of Large Software Systems, Winston W. Royce, Proc. IEEE WESCON, 1970，https://openalex.org/W2268265307
- 论文原文 PDF，https://cs.huji.ac.il/~feit/sem/se09/Waterfall.pdf
- Wikipedia: Winston W. Royce，https://en.wikipedia.org/wiki/Winston_W._Royce
- 争议：这篇论文常被误读为提倡单向瀑布流程，Royce 本人并不主张一次走完、也没用「瀑布」这个词。
