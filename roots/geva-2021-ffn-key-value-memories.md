# Transformer 前馈层是键值记忆（Transformer Feed-Forward Layers Are Key-Value Memories）

## 一句话

前馈层里每个神经元像一对“键-值”：键对输入里的某种文本模式起反应，值把输出推向某些词；整层输出就是这些记忆的组合，“单个神经元管某件事”从此有了能检验的说法。
