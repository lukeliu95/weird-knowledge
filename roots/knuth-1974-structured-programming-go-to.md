# 过早优化是万恶之源（Knuth《带 goto 语句的结构化编程》）（Structured Programming with go to Statements）

## 一句话

大约 97% 的时候应该忘掉小的效率问题，“过早优化是万恶之源”；先写出清楚易读的程序，再找出真正关键的那 3% 去优化。

## 原始出处

- Structured Programming with go to Statements, Donald E. Knuth, ACM Computing Surveys 6(4), December 1974，https://doi.org/10.1145/356635.356640
- 同上全文 PDF（Gwern 存档），https://gwern.net/doc/cs/algorithm/1974-knuth.pdf
- Program optimization，英文维基百科（When to optimize 一节），https://en.wikipedia.org/wiki/Program_optimization
- 争议：Knuth 后来把这句话归给 Tony Hoare，但 Hoare 2004 年表示不是他说的；维基百科认为这可能是 Knuth 记错了，一般以 Knuth 1974 年这篇论文为出处。
