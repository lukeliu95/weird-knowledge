# 《建筑模式语言》（A Pattern Language: Towns, Buildings, Construction）

## 一句话

列出 253 个建筑和城市设计模式，每个模式都是「反复出现的问题 + 解法」，模式之间互相引用、可以从大到小组合成一门「语言」，普通人也能用。

## 原始出处

- A Pattern Language, Christopher Alexander, Sara Ishikawa, Murray Silverstein, Oxford University Press, 1977，https://en.wikipedia.org/wiki/A_Pattern_Language
