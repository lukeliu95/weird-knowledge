# 代码注入（Code injection）

## 一句话

程序没有正确处理外部数据，把用户输入当成可执行的命令来运行，攻击者就能把代码“注入”到正在运行的程序里。

## 原始出处

- Code injection，英文维基百科，https://en.wikipedia.org/wiki/Code_injection

## 更底层的源头

- 已追到基础层，或暂未找到更底层的源头
