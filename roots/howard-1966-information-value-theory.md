# 信息价值理论（Information Value Theory）

## 一句话

一条信息值多少，看它能让决策的期望收益提高多少；问一个问题值不值得，要和问的成本比。

## 原始出处

- Information Value Theory，Howard，IEEE Transactions on Systems Science and Cybernetics 2(1): 22–26，1966，https://doi.org/10.1109/TSSC.1966.300074
