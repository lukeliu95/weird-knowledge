# Elvis：OpenClaw + Codex/Claude Code 智能体集群（一人开发团队）（OpenClaw + Codex/ClaudeCode Agent Swarm: The One-Person Dev Team [Full Setup]）

## 一句话

不再直接用编程 agent，而是让一个持有全部业务上下文的编排 agent（Zoe）去拆需求、写提示、选模型、给每个编程 agent 开独立的工作区；用确定性脚本定时巡检，以 CI、三家模型的自动评审和人工合并作为奖励信号，失败时带着业务上下文改写提示再重试。理由是“上下文窗口是零和的”，专业化靠上下文而不是靠换模型。
