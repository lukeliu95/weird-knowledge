# 决策树学习（Decision tree learning）

## 一句话

用一连串「某个属性是否大于某个值」的判断把数据切成多块，每块给一个类别；学出来的树能直接读成规则，也能翻译成查询条件。

## 原始出处

- Classification and Regression Trees, Leo Breiman, Jerome Friedman, Richard Olshen, Charles Stone, 1984（2017 年 CRC 再版），https://doi.org/10.1201/9781315139470
- Decision tree learning, Wikipedia，https://en.wikipedia.org/wiki/Decision_tree_learning
- 争议：维基百科说 CART 和 ID3 是差不多同一时期独立发明的，没有公认的唯一首创者；AIDE 用的是 CART。
