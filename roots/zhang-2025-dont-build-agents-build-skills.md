# 别再造智能体，去造技能（AI Engineer 演讲）（Don't Build Agents, Build Skills Instead）

## 一句话

智能体有智力但缺领域专长（找 300 IQ 的数学天才报税，不如找有经验的税务师）；与其为每个领域造一个智能体，不如做一个通用智能体（模型 + 运行时 + 文件系统和代码），连上 MCP 获取外部连接，再用技能提供专长；类比是模型像处理器、运行时像操作系统、技能像应用。
