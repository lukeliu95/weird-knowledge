# 输入假说（可理解输入，i+1）（Input hypothesis）

## 一句话

语言能力来自理解「比现有水平稍高一点」（i+1）的输入，在低焦虑、有兴趣的状态下下意识习得；克拉申认为输出本身不直接带来习得。

## 原始出处

- Input hypothesis, Wikipedia，https://en.wikipedia.org/wiki/Input_hypothesis
- Principles and Practice in Second Language Acquisition, Stephen D. Krashen, Pergamon, 1982（作者网站全文），https://www.sdkrashen.com/content/books/principles_and_practice.pdf
- 争议：被批评为难以检验，「习得与学得」的严格二分缺乏证据；斯温的可理解输出假说等认为只有输入不够。
