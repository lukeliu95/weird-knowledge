# 基于解释的学习（解释泛化）（Explanation-based learning / Explanation-based generalization）

## 一句话

只看一个解出来的例子，先弄清它为什么成立（用领域知识写出解释），再把解释里和具体数值无关的部分抽出来，泛化成能套用到一整类问题的规则。
