# 用户模拟的仿真到现实差距（Sim2Real Gap）（Mind the Sim2Real Gap in User Simulation for Agentic Tasks）

## 一句话

首次让 451 名真人跑完整 τ-bench 并对照 31 个大模型模拟器：模拟用户过度配合、风格单一、缺少真实的挫败和含糊，形成“简单模式”，把 agent 成功率抬到真人基线以上，给的反馈也一律更正面。
