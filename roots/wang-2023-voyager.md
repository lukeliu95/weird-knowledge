# Voyager：基于大模型的开放式具身智能体（不断增长的技能库）（Voyager: An Open-Ended Embodied Agent with Large Language Models）

## 一句话

在《我的世界》里不改模型权重、终身学习的 agent：自动课程负责找新任务，做成功的行为写成可执行代码存进不断增长的技能库，以后检索、组合来解新任务，再用环境反馈和报错迭代改提示。
