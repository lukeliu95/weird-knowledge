## 原文

Google just open-sourced its Harness²

It's a plug-and-play framework for recursive agent harnessing in an open world.

Agents can perform, and learn from, tasks its harness was never designed for.

Built around 8 components:

1. System prompt
2. Guardrails
3. Memory
4. Tool guidance
5. Subagents
6. Skills
7. Scripts
8. Plugins
