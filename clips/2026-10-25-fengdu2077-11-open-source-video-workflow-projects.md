## 原文

卧槽！新手小白一个人搭建视频工作流，要花钱的环节现在全被 GitHub 开源干掉了！
这 11 个项目装完，配音、动效、剪辑、封面一分钱不花🤯

其中一个本地版 TTS 一周狂涨 1.2 万星，HeyGen 官方开源的视频引擎也已经 7.1 万星了

先收藏再看，以后搭视频工作流就照着装👇

🎙 配音 / 声音
1. VoiceStudio：开源的本地版 ElevenLabs，声音克隆、声音设计、视频配音、转写、有声书全在一个软件里，8.4 万星，这周 GitHub 周榜涨了 1.2 万星，这个牛的！
https://t.co/6pLMdfVcg5

2. VoxCPM：面壁智能开源的 TTS，多语种，能用文字描述「设计」一个声音，克隆也很像真人，4 万星，今天又上了日榜
https://t.co/1ejGXVRB7z

3. YuE2-Studio：用自己显卡生成带人声的完整歌曲，还能出乐谱、改编，Windows 一键安装不用配 Python，BGM 再也不用到处找
https://t.co/Y28Bv3oeOd

🎬 画面与动效
4. HyperFrames：HeyGen 官方开源，写 HTML 就能渲染成 MP4，专门给 Agent 用，7.1 万星，做动效视频的人几乎必装
https://t.co/6JaSbcfvgo

5. Remotion 官方 skills：教你的 AI Agent 用 React 写视频，Remotion 团队亲自维护，5590 星
https://t.co/4u8V0Aqzue

6. motion-graphics：Claude Code / Codex 动效 skill，能直接按你的口播稿生成 B-roll 空镜
https://t.co/QmgHUgcHyS

7. motion-graphics-skills：13 个做产品发布级动效的 skill，每一帧都是代码，不用 AE 也不用视频生成模型
https://t.co/V30ww9D3w2

8. claude-motion-design：纯代码做动效视频，HTML + Playwright + ffmpeg 一条龙，不用 AE，也不用 Remotion 授权
https://t.co/2HUyRbp9cX

✂️ 剪辑 / 封面 / 出片
9. ffmpeg-skill：给 AI Agent 用的本地剪辑器，42 个 FFmpeg 工具，剪切、加字幕、改画幅、响度统一、按平台导出全能干，不上云、不要 API key，必装
https://t.co/maQDEQdpLC

10. youtube-agent-skill：11 个运营 YouTube 的 skill，21 种开头钩子公式写脚本，标题和封面成对检查，还能按字幕出剪辑清单、切 Shorts，2595 星
https://t.co/jfV1F9b4UU

11. Anatomy：让 AI 画可交互的等距机械拆解图，出的是 SVG，科技测评、硬件科普的封面配图直接有了，10 月 8 日才建仓就 1.98 万星
https://t.co/wvEIVLubzx

只要挑选好每个环节的工具串起来，比如：VoiceStudio 配好音，HyperFrames 渲染画面，ffmpeg-skill 剪成片，Anatomy 出封面。
一个人一台电脑，就可以组成一个视频团队了。

这一份就够打造一条优质内容流水线了！
