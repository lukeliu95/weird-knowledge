## 原文

有人利用AI在 24 小时内自动申请 1000 个职位并获得 50 个面试！ 🤯

这个叫Auto_Jobs_Applier_AIHawk 的AI求职机器人，代码开源在 GitHub 上了，目前12.7K 星。

求职环境发生了巨大的变化。求职者经常发现自己花了无数的时间浏览招聘信息，修改申请，重复填写表格。这个过程不仅会耗费时间，还会让人心力交瘁，错失一些机会。

主要特性：

- 扫描搜索符合条件的职位。自定义搜索条件，智能过滤，排除不相关的职位。

- 动态生成定制的简历。

- 自动找到页面上的职位申请按钮，自动填写和提交申请。

- 它使用 LLM 来个性化回答雇主的问题。

- 可以处理批量应用同时保持质量控制。

- 安全地管理您的数据并与 OpenAI 的 API 集成以实现 AI 驱动的功能。

- LLM 模型选择 (OpenAI、Ollama、Claude、Gemini)
