## 原文

Claude Code 刚刚通过逆向工程，在 90 秒内破解了我酒店房间的门锁。2014 年的加密技术。右上角的烟雾探测器也使用同一套协议——那个红色小灯不是电池指示灯。我启动扫描时，它闪了两次。

我现在躺在一个每晚 85 美元的酒店房间里。我打开 Claude Code，输入：「扫描范围内的每一台蓝牙和无线设备。告诉我哪些设备在与哪些设备通信。」

它找到了 19 台无线设备。其中 18 台是正常的。

设备 19：一个 BLE 控制器，使用着自 2014 年以来就没有修复过的固件。它控制着电子门锁、烟雾探测器、恒温器和房间里的保险箱。四台设备共用一个控制器。同一种协议。10 年没有任何更新。

我让 Claude Code 分析这套协议。整个过程用了 90 秒。

门锁使用一个 4 字节的滚动密钥，没有会话令牌。Claude Code 在第三次尝试时生成了一个有效的主密钥。我躺在床上，听见房间的门锁咔哒一声打开了。

接着，它发现烟雾探测器也连接在同一条总线上。照片里的红色小灯？那是控制器状态指示灯。它并不监测烟雾。它每隔 8 秒就会确认一次与门锁系统之间的 BLE 握手。

这意味着，任何处于蓝牙覆盖范围内的人——走廊、隔壁房间、停车场——只需要一条提示词和 90 秒，就可以：

打开你的房门
关闭房间内的警报
打开你的保险箱
而烟雾探测器会通过那个小小的红色闪烁，确认连接状态

检查只需要 2 分钟：

步骤 1 → 打开 Claude Code → 粘贴第一条评论中的提示词

步骤 2 → 它会扫描覆盖范围内的每一台 BLE 设备，并标记存在未修复固件的设备

步骤 3 → 如果发现问题 → 要求更换房间 → 要求换到配有机械门闩的房间 → 然后使用那个房间

每一家使用 2018 年之前生产的 ASSA ABLOY 或 Onity 门锁的酒店连锁都存在这个问题。这大约占全球酒店的 30%。

我本周测试了 3 家酒店。3 家全部存在漏洞。

看看照片。右上角。那个每隔 8 秒闪烁一次的红点。那就是握手信号。

保存这条提示词。下次入住酒店时 → 先运行它，再打开行李。
