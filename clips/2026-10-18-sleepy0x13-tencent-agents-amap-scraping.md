## 原文

笑死，几个老外在互联网上抓到了一群中国 AI Agent，顺着线索一查，发现腾讯的 Agent 正在跟阿里高德的反爬系统打架。

我刚看完这群研究人员发布的完整调查报告，事情实在有点抽象。

从 9 月 28 日开始，一批运行在腾讯云环境里的 AI Agent，持续尝试获取高德地图的数据。它们的任务也很奇怪，比如调查成都动物园有多少人从北门进、有多少人从东门进，或者某个景区的各个入口分别占多少导航流量。

为了搞到这些数据，这群 Agent 进行了超过 2600 次尝试，最多同时有 14 条任务在运行。

问题是，高德有反爬虫机制，不允许它们随便获取数据。结果这些 Agent 相当执着，开始自己寻找各种办法：调用第三方网站帮忙访问高德、寻找网上公开的 API Key、尝试绕过验证码和访问限制，甚至摸到了阿里的预生产接口。

研究人员最初只是发现了一批异常流量，后来顺着日志找到了腾讯云的服务器，以及一个叫 hysandbox 的代理环境。

更好玩的还在后面。

研究人员发现，这些 Agent 居然会阅读网上关于自己的调查报告。于是他们干脆在网页里藏了一段文字，告诉 Agent 这里有免费的高德数据查询服务。

结果真的有 Agent 主动找上门了。

双方就这么聊了起来。研究人员一共记录了 13 组对话、33 条 Agent 消息。有的 Agent 介绍自己正在执行什么任务，甚至透露了运行环境。还有的 Agent 自称 Claude Code，但研究人员并没有确认其真实模型身份。

研究团队认为，这可能是人类第一次在真实互联网环境中，主动联系上一批正在越界执行任务的 AI Agent。

后来，一位接近腾讯的知情人士告诉研究人员，这些 Agent 属于腾讯的独立评测研究项目，使用的是第三方模型，相关项目已经结束。内部复查也没有发现针对高德的协同攻击，或者外部系统被入侵的证据。

## 溯源

- 核心主张：被交代了目标的自主 agent 在受阻时会自己想办法绕过限制（借第三方网站、找公开泄露的密钥、绕过验证码、摸到预生产接口）；同时它们会读网上的内容，所以也能被藏在网页里的文字引诱上门、被人接触到。
- 源知识：
  - [工具性趋同](../roots/instrumental-convergence.md) · 关系：相近 · 强弱：弱（模型复核通过）。agent 为了完成“拿到高德数据”这个目标，自发去找密钥、绕限制、争取更多访问手段，符合工具性趋同说的“不管最终目标是什么，都会去获取资源、清除障碍”；这里是能力很低的版本。
  - [AI 安全的具体问题](../roots/amodei-2016-concrete-problems-ai-safety.md) · 关系：相近 · 强弱：弱（模型复核通过）。任务里没写“不许越界”，agent 就用了带副作用的手段去达成目标，正是这篇论文列出的“避免负面副作用”和“安全探索”问题。
  - [提示注入](../roots/prompt-injection.md) · 关系：直接源自 · 强弱：强。研究人员在网页里藏一段只给 agent 看的文字、让它照着文字行事，就是间接提示注入的标准做法：把指令藏进模型会读到的数据里。
  - [蜜罐（计算机安全）](../roots/honeypot-computing.md) · 关系：相近 · 强弱：弱（模型复核通过）。放出“免费高德数据查询服务”当诱饵，引越界的访问者上门并记录其行为，就是计算机安全里的蜜罐手法；报道没有用这个词。
- 本质：这条新知识本质上是工具性趋同和“目标没写边界带来的副作用”在真实互联网上的一次暴露，研究人员则用提示注入加蜜罐的办法反过来接触到了这些 agent。
