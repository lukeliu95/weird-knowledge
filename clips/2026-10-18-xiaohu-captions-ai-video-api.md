Captions 推出一些列AI视频生成和编辑功能的API套件 

开发者可以利用其API套件大规模地生成、编辑和翻译对话视频。

这些API包括：

-生成社交媒体对话视频的 AI Creator API

-克隆自己生成个性化视频的 AI Twin API

-自动批量编辑几百个视频的 AI Edit API

-以及用于本地化和翻译的 AI Translate API

AI Creator API：

AI Creator API 是一种强大的工具，允许用户通过编程方式生成对话视频。该API主要用于创建用户生成内容（UGC）风格的视频，适合广告或有机视频的批量生成。
