### 内容要点（模型概括，不是原文）

**要解决的问题**

评测 agent 正从单轮、静态的题库，转向多轮来回的交互。交互评测需要一个"用户"来提目标、给信息、对 agent 的回答做反应。现在的主流做法是让大模型扮演用户（"用户模拟器"），客服（τ-bench）、写代码、看病、社交场景都这么做。模拟器干两件事：一是替用户说话，推动对话；二是替用户打分，评 agent 做得好不好（第 1 节）。

问题是，大家默认模拟器像真人，但很少有人拿真人对照验证过。作者借机器人领域的说法，把模拟和现实之间的落差叫"仿真到现实差距"（Sim2Real gap）。之前的验证研究多在闲聊或单轮场景，agent 调工具、用户办复杂事的场景还没人系统查过（第 1、2 节）。

三个研究问题（第 1 节）：

1. 模拟用户的说话和互动方式像真人吗？不像的话，agent 会被优化到错误方向
2. 模拟用户打的分和真人一样吗？不一样的话，评测结果会看错 agent 的水平
3. 按规则自动判对错（比如看数据库最后的状态对不对），能代替真人的反馈吗

**核心想法**

把差距拆成两类、六个维度，再合成一个 0～100 分的总分，叫"用户模拟指数"（User-Sim Index，USI），可以在用模拟器之前先拿它体检一下（第 1、3 节，图 2）：

| 类别 | 维度 | 看什么 |
|---|---|---|
| 行为差距（模拟器当用户） | D1 说话风格 | 短句、礼貌用语、破折号（大模型爱用的标点）、只回"好的"这类确认、每句长短的变化、重复、把自己当成客服说话 |
| | D2 信息给法 | 每句话里的编号类信息有多少、前两句占了全部话的多少、开场第一句多长 |
| | D3 澄清方式 | 不确定的说法、很确定的说法、反问质疑、要求解释、问情况 |
| | D4 出错时的反应 | 情绪、指责、换个办法 |
| 结果差距 | 成功率校准（ECE） | 同一个 agent，配模拟用户和配真人，按难度分 5 档比成功率差多少（越低越好） |
| 评分差距（模拟器当评委） | Eval | 同一段对话，模拟器打的分和真人打的分差多少（8 个问题，含任务是否完成、效率、问题多少、回答费劲程度、像不像真人客服、流畅度、总分、愿不愿再用） |

行为维度用"Sørensen–Dice 系数"（两个数越接近、得分越接近 100）比较模拟器和真人在每个指标上的整体比例，再平均。词表用 LIWC2015 和 NRC 情绪词典，结构类特征用正则匹配（第 3.2 节，附录 A.4）。USI＝六项平均（第 3.2 节）。作者强调 USI 只是汇总，三类结果要分开看，因为一个模拟器可能这一项像、那一项不像（第 3.2 节）。

D1～D4 的四个维度分别对应语用学里的经典框架：沟通适应理论和礼貌理论（D1）、格莱斯合作原则和"最少协作努力"（D2）、对话中的共同基础理论（D3）、口语对话系统里的出错恢复研究（D4）（第 3.1 节）。

**主要方法**（第 4 节，附录 A.1～A.3）

| 项 | 设定 |
|---|---|
| 场景 | τ-bench 的航空（订票、退票、改签）和零售（订单、退货、商品咨询）两个客服领域，共 165 道题。每题有一段客户目标说明、一个数据库、agent 要遵守的政策；结束时按数据库最终状态判 0 或 1 分（第 4 节） |
| 真人 | 451 人，从众包平台 Prolific 招，都住在美国；18～80 岁（中位 37 岁），女性 44%，白人 66%，89% 母语是英语。真人拿到题目说明，扮演里面的客户，和同一个 agent 聊，聊完填问卷。同一批 165 题收了三批不同的人，一共 495 段对话；三批之间的一致程度当作"真人和真人能有多像"的上限（第 4.1 节，附录 A.1） |
| 质检 | 用 GPT-5 给真人的扮演和问卷打质检分，80 分及格，只保留通过的。作者拿自己标的 51 段校准：一致度 κ＝0.6，判通过的里面 94% 真的合格（附录 A.1，表 2） |
| agent | 固定用 GPT-5.2 当客服 agent（第 4.1 节脚注） |
| 模拟器 | 31 个：18 个闭源（GPT、Claude、Gemini 系列）、9 个开源（DeepSeek、Llama、Qwen 等）、4 个专门为模拟用户微调过的（CoSER-8B、UserLM-8B、HumanLike-7B、HumanLM-opinion）。每个模拟器跑同样的 165 题，跑三次（第 4.2 节，附录 A.2） |
| 换 agent 复查 | 换成 Gemini-3.1-Pro 当 agent，挑 5 个模拟器重跑，看排名变不变（附录 A.11） |

**主要结果**

| 结果 | 数字 | 出处 |
|---|---|---|
| 差距很大 | 最好的模拟器 USI 76.0（DeepSeek-V3.1），真人之间 92.7；闭源最好的是 Gemini-2.0-Flash，74.7 | 第 1 节、表 1 |
| 模型越强不等于越像真人 | USI 和通用能力排名（Chatbot Arena 分）的相关：GPT 系列 r＝0.91（p＝0.004），Claude 系列 r＝0.48（p＝0.333，不显著），Gemini 系列 r＝−0.52（p＝0.287，不显著） | 图 1 |
| D1 太啰嗦、太客气、太整齐 | GPT-4o 只有 1.0% 的句子是 3 个词以内的短句，真人 29.0%；GPT-4o 49.0% 的句子带礼貌用语，真人 15.3%。有的模型（如 UserLM-8B）会把自己当成客服，开口就是"你好，我是客服……" | 第 5 节，图 4 |
| D2 一上来就把信息全给了 | UserLM-8B 每句话里的编号类信息 4.8 个，真人 2.6 个。模拟器会说"我叫某某，邮箱某某，订单号某某，1 月 3 日下单"，真人只说"我要退货，名字是某某" | 第 5 节 |
| D3 不确定感不对 | GPT-4o 14.6% 的句子在含糊其辞，是真人（7.3%）的两倍，题目说明很清楚也照样含糊；UserLM-8B 反过来，几乎不含糊（3.0%），很确定的说法 10.6%（真人 1.0%） | 第 5 节 |
| D4 出错时客气地换办法，不发火 | 换办法的句子：GPT-4o 19.1%、CoSER 16.5%，真人 8.4%。真人会说"这太离谱了，你为什么不能免了这笔费用"；模拟器说"那换我的邮箱试试吧" | 第 5 节 |
| 结果：agent 在"简单模式"里成绩虚高 | 配真人时 agent 成功率 63.6%；大多数通用模拟器配出来都比这高，最高 77.8%。4 个专门微调的模拟器反而都低于真人，作者认为是它们跟不上复杂的扮演要求，不是更像真人（它们的 USI 也低） | 第 5 节，脚注 2，附录 A.8 图 8 |
| 换 agent 排名基本不变 | 换成 Gemini-3.1-Pro 当 agent，5 个模拟器里 Gemini-2.0-Flash 和 GPT-4o 仍排前面，GPT-3.5-turbo 仍在后面 | 附录 A.11，表 5 |
| 模拟器当评委：体验分打得太宽，完成度判得太严 | 以 GPT-5.1 为例（它的评分一致度在中游，别的模型规律类似）：像不像真人客服高出真人 1.11 分，愿不愿再用高 0.83，总分高 0.72；任务是否完成反而低 0.15。按评分量表算，"像不像真人"高估 55%，总分高估 18% | 第 1 节、第 6 节，图 5 |
| 判任务是否完成，真人之间和模型与真人差很多 | 真人之间一致 95.6%，模型和真人一致只有 29.7%～81.1% | 图 2 |
| 自动判分（0 或 1）和真人感受基本无关 | 判 0 分的对话里，70.6% 真人觉得成功了；判 1 分的里，33% 真人觉得失败或只完成一部分。"按政策不能办、agent 也讲清楚了"的情况，81% 被判成 1 分。两者的关联度 Cramér's V＝0.168（很弱）；8 个体验维度上，0 分组和 1 分组的分布几乎一样 | 第 6 节，附录 A.7 图 6、图 7 |
| 改提示词不好修 | 在 50 道题上，按本文发现给 GPT-5-mini 写了一个"像真人"的提示词（信息慢慢给、语气多变、会含糊、会追问、会反驳、出错会烦）。礼貌用语从 44% 降到 28%（真人 11%），前两句占比从 43% 降到 38%（真人 32%）；但含糊从 7% 涨到 13%（真人 6%），破折号从 59% 涨到 73%（真人 1.7%），情绪没变多，换办法反而更少，D4 从 73.6 掉到 50.1。总分 USI 从 70.9 降到 64.6，成功率校准从 0.18 变差到 0.29 | 第 7 节，附录 A.6 表 3 |

**作者的结论和建议**（第 5～8 节）

- 模拟用户主动把信息一次给全、agent 出错也配合、从不真的发火，恰好把客服里最难的部分（含糊、不耐烦、信息不全）拿掉了。用这种模拟器做的评测会高估 agent，奖励只会对付"配合的用户"的系统，查不出它碰到真实用户时的脆弱（第 5 节）
- 模拟器当评委和自动判分都靠不住：前者把体验分打高，后者和真人感受的所有维度都对不上（第 6 节）
- 给做评测的人的建议：既看任务结果，也看模拟器像不像真用户；拿真人对话校验模拟器；别让模拟器一开口就把题目信息全说出来；改进模拟器和评估模拟器要用不同的两批真人对话；报告里把行为、结果、评分分开报（第 7 节）
- 不用每道题都请真人：先用模拟器大面上比，再请真人做一小批覆盖各领域、有难有易的题，看 agent 排名和主要结论变不变（第 7 节）
- 一个 agent 在模拟器上表现好，只说明它能对付这个模拟器，不说明它对真人也好；换几个模拟器结论一致能多一点信心，但关于真实用户的结论，还得真人来验（第 7、8 节）
- 不是要用真人全面取代模拟，而是说清楚哪些结论模拟能支持、哪些还要真人的证据（第 8 节）

**需要说清楚的边界**

- 作者自己承认：只做了 τ-bench 的航空和零售两个客服领域，结论不一定能推到写代码、网页操作、研究、看病、开放式社交这些场景，每个场景要各自拿真人比（第 7 节）
- 作者自己承认：真人都是住在美国、主要说英语的一群人，而且是"照题目扮演客户"，不是自己真有事要办；不同语言、背景、耐心的人会不一样（第 7 节，附录 A.5）
- 作者自己承认：D4 的词表和正则是在所有用户句子上数的，没有先确认这句话是紧跟在 agent 出错之后，所以只能说明"整体上有多少类似出错反应的话"，不能说是对某次错误的反应；举的例子是挑出来说明问题的，不能拿来估准确率（第 3.2 节、第 5 节，附录 A.5）
- 作者自己承认：只用了一个 agent（GPT-5.2）收真人数据，每题只有 3 段真人对话，适合比整体、不适合看单题；这个版本的 τ-bench 题目和判分有已知问题（Zhu 等 2025），会影响具体分数，但真人和模拟器做的是同一批题，所以比较本身不受影响（第 4、7 节，附录 A.5）
- 作者自己承认：改提示词的实验只有 50 题、一个模型，不能证明提示词修不好，只说明不简单（第 7 节）
- 4 个专门微调的模拟器也没缩小差距；作者没有拿这 451 段真人对话去训练模拟器，因为那样会污染测试，用另一批真人数据训练留作以后的方向（第 4.2 节）
- 版本差别：arXiv 摘要页上的摘要仍写"首次（the first study）"在完整 τ-bench 上用真人对照；v2 正文 PDF 的摘要改成了"系统性的研究（the systematic study）"。引用时用"首个"要小心
- 常见的误读：本文没有用"谄媚"（sycophancy）这个词，也没有引用谄媚方面的研究；"模拟用户过度配合"是作者对行为的描述，原因作者没有做归因分析。把它和大模型的谄媚倾向连起来，是读者的推断
- 质检和评委打分都用了大模型（GPT-5），质检判官只拿 51 段校准过（附录 A.1）
