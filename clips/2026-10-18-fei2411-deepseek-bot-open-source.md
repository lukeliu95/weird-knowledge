## 原文

正式介绍开源的 DeepSeek Bot ！（非官方）

DeepSeek Bot ( 简称ds bot ) 是一款基于 DeepSeek Harness ( 简称 dsh ) 的开源插件，让你能够拥有一组持久化的 Bot，使用你自己的 API Key。你可以和你的 Bot 聊天、工作，或者做任何你想做的！

你可以为 ds bot 接入任何你想接入的模型，甚至在未来，你可以直接接入你的本地 agent，这意味着你可以使用自己已有的 ai 订阅。

ds bot 继承了 dsh 的“一切皆插件”理念，未来将会有更多可拓展性，迫不及待想看到会发生什么！

仓库地址：https://t.co/qMw3z9QYT4
安装：在dsh desktop插件页输入: ds-bot
