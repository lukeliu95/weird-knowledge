## 原文

**厂商调查**：ネオマーケティング是东证标准市场上市的调研公司（日本市场调查协会会员），同时卖 BtoB 营销支援和"调查 PR"（用调查结果做公关内容）。这份调查本身就是它的调查 PR 产品，结论"营业资料要重新设计"和它卖的服务一致。样本：用自家问卷系统，对象是"最近 1 年内以批准、提案或收集信息任一身份参与过 BtoB 商材导入社内稟議的日本 BtoB 企业员工"，有效回答 540 人，2026 年 8 月 17～18 日。没有写配额、加权、三种身份各多少人。这里只存要点。

- 标题：BtoB企業の社内稟議・承認プロセス実態調査2026（副标题：営業提出資料の約4割は「役に立たなかった」――稟議は"準備量"では通らない）
- 解说文（多了按商材分类、按金额分的数据）：https://corp.neo-m.jp/column/btob-marketing_027_ringi-approval-rate-2026
- 同内容的 PR TIMES 稿：https://prtimes.jp/main/html/rd/p/000000717.000003149.html （只核实了标题）
- 读了多少：调查报告页全文 + 解说文全文（内置浏览器）。完整 PDF 要填表下载，没下

### 内容要点（模型概括，不是原文）

**要解决的问题**：日本企业的稟議书里写了什么、靠什么根据通过、卖方提供的材料到底有没有用。

**主要结果（全体 n=540，除非另注）**

| 结果 | 数字 | 出处 |
|---|---|---|
| 稟議书平均写几项（13 项里，如背景课题、费用、期待效果） | 4.35 项 | 报告页"6割の壁"一节 |
| 准备的根据数据平均几种（14 种里） | 2.91 种 | 同上 |
| 最近一次稟議被退回修改过 | 57.2% | 同上 |
| 过去 1 年稟議没通过、放弃导入 | 57.8% | 同上 |
| 批准要点第 1 名"明确的费用效果" | 43.7% | 报告页"費用対効果"一节 |
| 批准要点"公司内优先级""和经营课题一致" | 30.6%、30.4% | 解说文"ポイント3" |
| 实际把 ROI 试算当根据准备了 | 19.3%（15 项里第 7） | 报告页"費用対効果"一节 |
| 用过 ROI 试算的人里，说它"非常有影响"（n=104） | 33.7%（15 项里最高） | 同上 |
| "最有说服力的根据"（单选）：营业的提案书 / 自家销售实绩 / 他社导入事例 / ROI 试算 | 14.6% / 14.1% / 9.3% / 8.5% | 报告页"稟議を動かす根拠"一节 |
| 政府统计、民间调研公司数据这类第三方数据被选为最有说服力 | 各不到 4% | 同上 |
| 稟議书里写了"ROI"的比例：合同金额 50 万日元以下 → 3,000～5,000 万日元 | 5.8% → 53.8% | 解说文"契約金額別"图下 |
| 写了"投资回收期"：同上 | 4.9% → 50.0% | 同上 |
| 参与批准的人数和期间：50 万日元以下 → 3,000～5,000 万日元 | 平均 3.0 人、3.3 周 → 8.6 人、11.4 周 | 同上 |
| 稟議时觉得缺的信息：导入效果 / 风险信息 | 33.3% / 31.7% | 解说文"ポイント2" |
| 稟議书里实际有"风险"一项 | 23.9% | 同上 |
| IT 系统和 SaaS（n=92）：平均合同额、批准人数、批准期间、没被退回的比例 | 2,228 万日元、5.53 人、9.0 周、32.6% | 解说文"商材カテゴリー別"表 |
| IT 系统和 SaaS 被退回的第一原因（退回过的 n=62） | 风险担忧 46.8% | 解说文"差し戻しの理由"表 |
| 生成 AI 相关服务被退回的第一原因（n=52） | 风险担忧 38.5% | 同上 |
| 卖方给的材料（14 种、合计 1,400 次提供）里真的帮上稟議的 | 59.8% | 报告页、解说文 |

**卖方给的材料：给了多少、帮上多少**（解说文表格；"提供率"以全体 540 人为分母，"有用率"以收到的人为分母）

| 材料 | 提供率 | 有用率 |
|---|---|---|
| 报价单 | 35.2% | 73.2% |
| 竞品比较表 | 19.4% | 67.6% |
| 提案书 | 28.0% | 66.2% |
| 第三方调查数据 | 11.3% | 63.9% |
| 导入事例 | 23.7% | 63.3% |
| 行业内导入率、使用率数据 | 18.0% | 59.8% |
| ROI 试算表 | 14.8% | 58.8% |
| 给经营层的说明材料 | 19.3% | 58.7% |
| 陪同或代为向经营层演示 | 13.5% | 53.4% |
| 稟議书、社内申请书的模板 | 17.2% | 52.7% |
| 公司介绍 | 18.1% | 50.0% |
| 预想问答集 | 15.2% | 48.8% |
| 演示、试用环境 | 11.5% | 48.4% |
| 安排拜访已导入企业 | 14.1% | 44.7% |

（核对：14 项提供率加起来 259.3%，乘 540 约等于 1,400 次，和原文"延べ1,400件"对得上）

**需要说清楚的边界**

- 回答者混了批准人、起案人、收集信息的人三种身份，公开页面没有分开统计，"有用"是谁觉得有用不清楚
- "最有说服力"是单选，每项都只有一成多，差距很小，不能说"提案书远胜 ROI"
- 按商材分类的 n 有的只有 12～30，作者自己也说只能当参考
- "费用效果"排第 1，但"缺的信息"里导入效果和风险几乎并列，IT 和 SaaS 被退回的第一原因是风险担忧而不是费用效果
- 报告页的"调查发现"列表里混进了一条讲自行车取缔的内容（61.6%、40.0%、62.1%），明显是别的调查贴错了，说明这页编辑不严，引用前最好下载完整 PDF 再核一次
- 有用率是自报印象，不是对比过有没有这份材料时的通过率

## 溯源

- 核心主张：日本企业的稟議最看重费用效果和风险，但起案人很少准备 ROI 试算；卖方给的材料里，报价、比较表、提案书这类能直接拿来做判断的最有用，稟議模板、演示这类反而一般。
- 源知识：
  - [稟議制](../roots/ringi-system.md) · 关系：直接源自 · 强弱：强。调查对象就是稟議
  - [采购中心（决策单元）](../roots/buying-center.md) · 关系：相近 · 强弱：强。金额越大批准人越多（3.0→8.6 人），是采购中心随风险变大的老结论
  - [感知风险](../roots/perceived-risk.md) · 关系：相近 · 强弱：弱（待 Luke 确认）。IT 和 SaaS 被退回的第一原因是风险担忧，符合感知风险理论，但调查没有引用
  - [Gartner 新 B2B 购买旅程（购买任务与买方赋能）](../roots/gartner-2019-b2b-buying-journey.md) · 关系：相近 · 强弱：弱（待 Luke 确认）。"卖方给的材料帮买方过稟議"就是买方赋能；但这里只有 59.8% 有用，提示不是给了就有用
- 本质：这条本质上是稟議制在 BtoB 采购里的现状：一群人按金额层层把关，起案人缺的是能直接用来回答"值不值、有没有风险"的材料。
