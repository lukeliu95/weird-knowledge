## 原文

别再傻傻骗赞了！马斯克早就把 X 的推荐代码开源了。扒完代码才发现，在这个算法里，“点赞”就是弟中弟。

官方权重表直接贴给你们，看懂的流量都已经起飞了：

👍 点赞 (Like)：0.5 分（基本没用） 
🔁 转发 (RT)：1.0 分
👀 点进详情页停留 2 分钟：10.0 分（完读率很贵） 
💬 直接回复 (Reply)：13.5 分（比点赞强 27 倍！） 
🔥 回复后，作者回复你：75.0 分（这才是核武器！！）

⚠️ 高能预警：被拉黑/点不感兴趣：-74 分被举报：-369 分（直接进小黑屋）

结论非常残忍：一条 100 赞 0 评论的帖子，权重可能不如一条 5 个赞但有 2 个人在评论区吵架的帖子。

想做爆款？记住这 3 条铁律：

1、必须以此引起讨论（哪怕是让人想反驳）。
2、必须回复评论（那是 75 分的加成，不是礼貌，是流量！）。
3、把帖子写长一点/做成 Thread（骗停留时长）。

最后一句话：想在 X 上爆，不要只求“赞”，要设计“停留 + 回复 + 来回对话”。

算法喜欢的不是你多会写，而是你能不能让人“参与”。

## 溯源

- 核心主张：X 开源的推荐算法给不同互动设了不同权重，回复、作者回复、点进去停留远高于点赞，负反馈会被重罚，所以想要分发就要设计讨论和来回对话，而不是求赞。
- 源知识：
  - [Twitter 推荐算法开源（Heavy Ranker 互动权重表）](../roots/twitter-2023-recommendation-algorithm.md) · 关系：直接源自 · 强弱：强。原文贴的 0.5、1、10、13.5、75、-74、-369 与 twitter/the-algorithm-ml 仓库 README 公布的 2023-04-05 版 Heavy Ranker 权重一字不差。但有三处要注意：一是权重乘的是“这个用户会做这件事的预测概率”，不是帖子上已有的赞数和评论数，所以“100 赞 0 评论不如 5 赞 2 人吵架”是误读；二是 README 说权重最初设定成让每种互动对平均分的贡献大致相等（回复权重高主要因为回复少见），“回复比点赞强 27 倍”不等于一条回复顶 27 个赞的实际流量；三是“让人想反驳”可能触发 -74 的负反馈。
- 本质：这条新知识本质上是推荐系统的排序学习（预测每种互动的概率再加权求和打分）在 X 内容分发上的应用：创作者顺着平台的打分函数设计内容。
