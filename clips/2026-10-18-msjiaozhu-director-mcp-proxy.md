## 原文

Director 有点东西！它将 MCP 都统一成了一个接口！ 

这相当于是一个 MCP 服务代理，本地启动，然后通过UI或命令行，把五花八门的 MCP Server 全都加进去。你的 AI 只需要调用这一个 MCP，就能使用所有工具。

 后续扩展新的 MCP 也只是点几下鼠标的事。
