## 原文

在做投资分析或市场研究，我们需要从不同网站收集股价、财报、新闻等信息，来回查找颇为耗时。

现在只需要给 AI 助手装一个 Financial Datasets MCP 服务器，即可在同一对话中直接获取相关实时数据。

比如查询公司的损益表、资产负债表、现金流量表，还能获取股票价格、市场新闻等等信息。

GitHub：https://t.co/dD8BY4ta8u

除此之外，还支持加密货币数据查询，并提供所有可用加密货币代码列表。

通过 Python 和 uv 包管理器安装后，配置 API 密钥即可在支持 MCP 的 AI 助手上使用。
