以前让 Claude Code 上网搜个东西，推特 API 要钱，网页抓取要订阅，B站小红书直接给你拦在外面。每个平台一个门槛，烦得要死。

Agent-Reach，一个免费开源仓库，一条命令把这 14 个平台全通了。
