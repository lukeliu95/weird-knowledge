## 原文

原推这个是解释 UI SDK 最清楚的一个视频，毕竟是原作者，不过没有语音看着有点累，加上了配音，这样看就轻松多了。

UI SDK 很聪明的把 UI 组件拆成了 Agent 能用的行为原语，比如打开弹出层、方向键移动焦点，这样带来的好处就是可以组件无关，可以让 Agent 直接组合应用到 React、Vue、Svelte、Solit 等不同的框架。

具体建议看视频可以文档。 https://t.co/cbEhKeDWlk

注意视频中的“我们”是指 shadcn/ui 团队。
