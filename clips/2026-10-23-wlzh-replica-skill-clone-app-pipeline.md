## 原文

有人把"抄一个 App"这件事，做成了一套正经流水线。

GitHub 上这个 replica-skill，3,985 星，是给 Claude 用的 11 个技能，免费、MIT，不用注册也不用 API key。

流程是连着走的：先侦察，把目标 App 的界面、流程、组件、数据模型从公开页面、截图和应用商店介绍里扒出来；再定架构、扒设计规范，然后逐屏重建，接上登录、数据库和支付。

后面几步才是精髓：一个技能专门点遍所有流程测 bug；一个把克隆版和原版逐项对比打分，差在哪列得清清楚楚；还有一个叫 Entrepreneur 的，去翻原版在 App Store、G2、Reddit 上的真实差评，把用户最恨的几点变成你这版的修复清单和卖点。

作者在细则里把丑话说得很明白：只重建功能和交互，净室做法，不碰人家的源码、logo、文案和私有接口；上线前必须换名、换配色、换品牌，有个扫描工具专门查代码里还残留没残留原版的东西，不干净就不让发布。

他也承认克隆不是万能的：订票工具这种几周能搞定，表格引擎那种就别想了，侦察那步会先老实告诉你这活有多大。

想抄作业抄得理直气壮的，这套流程值得看看。https://t.co/05D5xRxT1n
