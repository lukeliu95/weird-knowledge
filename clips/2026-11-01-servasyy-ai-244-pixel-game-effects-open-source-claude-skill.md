## 原文

爽了！打死我都不敢信，居然有人把这种东西全开源了！！！

    244 种顶级游戏像素特效，爆炸、闪电、火焰、冰冻、传送门、魔法阵、大招连击……

    别人在素材站打包卖几百几千块的东西，这老哥倒好，直接 MIT 协议一锅端全免费开源了，随便商用😂

    关键是，这些根本不是死板的视频素材，而是纯代码实时画出来的。。。

    而且它最牛逼的地方，是直接自带了一套 Claude Code Skill！

    我翻了一圈，来给大家详细讲一讲它有多香：

    1、244 种特效全靠代码实时生成，零图片素材：每一帧都是纯 JS
    算出来的，自带发光图层。直接打开网页就能实时预览，随便换颜色、改大小、镜像翻转，火球一秒变幽冥蓝火，完全不用求着美术改图。

    2、连《死亡细胞》那种卡肉打击感都给你写好了：普通特效贴上去像张死贴纸，这项目直接用代码搓了个 3D
    骨骼像素假人，把攻击前摇、命中顿帧、震屏幅度、受击击退全做成了现成参数，一套连招下来丝滑得离谱。

    3、把 Claude Code 调教成了你的专属特效师（最狠的一点）：以前让 AI 写动画全是廉价塑料感。它直接把“写代码 → 本地渲染多帧网格图 → AI
    自己看图找茬 → 自动查越界掉帧”做成了一个现成 Skill。你直接对 AI
    说一句："给我法师大招加个冰霜新星，打击感再重一点"，它自己边看图边改，直到改顺眼为止。

    4、全引擎通吃，一键导出精灵图：做网页小游戏直接拷代码就能跑；用 Unity、Godot，或者做像素风动画、AI 视频的，跑一条命令直接导出透明背景的
    Sprite Sheet（精灵图），拿来就能用。

    说白了，不管你是独立开发者搓游戏，还是做像素风动画视频，这一下直接省掉几千块买素材和请美术外包的钱。
