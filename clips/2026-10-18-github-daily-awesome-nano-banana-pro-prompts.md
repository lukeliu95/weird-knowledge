## 原文

这周有空就在玩 Nano Banana Pro 生成图片，有时不知道该怎么写提示词才能出好图，各种风格和技巧一直在摸索，但效率很低。

偶然间，在 GitHub 上发现 awesome-nano-banana-pro-prompts 这个开源项目，收集了 500+ 精选的 Nano Banana Pro 提示词案例。

项目按照不同应用场景分类整理，涵盖海报设计、信息图表、品牌视觉、角色设计等多种类型，每个案例都配有生成的图片效果。

GitHub：https://t.co/nCztd24yS0

支持多语言提示词，提供即时图库预览功能，可以直接看到每个提示词的实际生成效果。

目前项目在持续更新中，如果你想快速掌握 Nano Banana Pro 的提示词技巧，而不是从零摸索，这个项目值得收藏。
