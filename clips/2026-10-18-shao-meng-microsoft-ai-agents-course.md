## 原文

微软全新推出 AI Agent 入门基础课程

课程包含十个教单元，涵盖了构建 AI Agent 的全部基础知识，每个单元都专注于一个特定主题，你可以从任何感兴趣的地方开始学习。

课程单元
1. AI Agent 介绍及用例
2. 探索 Agent 框架
3. 理解 Agent 设计模式
4. 工具使用设计模式
5. Agentic RAG
6. 构建可信 AI Agent 
7. 规划设计模式
8. Multi Agents设计模式
9. 元认知设计模式
10. 生产环境中的 AI Agent

技术与框架
这个课程使用了几种主要的模型服务和AI Agent 框架：
- 模型服务：
  - GitHub Models（免费但有限制）
  - Azure AI Foundry（需要Azure账户）
- AI Agent 框架：
  - Azure AI Agent Service
  - Semantic Kernel
  - AutoGen @pyautogen

特色与亮点
- 多语言支持：提供包括简体中文、繁体中文、法语、日语等在内的多种语言版本
- 实际代码示例：每个课程都包含可运行的代码示例
- 开放贡献：欢迎社区参与改进课程内容
- 资源丰富：每个单元都提供额外学习资源的链接
