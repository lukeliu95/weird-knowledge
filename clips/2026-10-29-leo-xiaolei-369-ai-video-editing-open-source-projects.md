# 我评估了 369 个 Claude/CodeX AI 视频与自动化剪辑开源项目

在 AI Agent 辅助编程与自动化内容生产极速狂飙的今天，我花时间系统整理了一份包含 369 个开源仓库的超级清单。这份清单全面涵盖了能让 Claude Code、Codex 等编程 Agent 实现视频生成、自动化剪辑与代码动效渲染的工具包、Skill 和提示词库。

在这次深度梳理中，我刻意打破了常规的“GitHub 高星滤镜”——因为我发现，星数并不能完全代表真实的生产力。在这个日新月异的赛道里，一些刚刚建库、甚至只有个位数 Star 的项目，往往正在解决极为刁钻、具体的行业痛点。

我的收录规则非常克制，只保留以下三条底线：

1. 必须围绕视频或动效产出。 纯 3D 网页不收录；必须是代码渲染出画面，且能够交给 Agent 重做的成片或提示词。

2. 必须是专供 Agent 调用的工具。 包含 Skill、插件、MCP，或明确为 Claude Code、Codex 等 Agent 打造的工具包。

3. 必须有完整的 README 文档。 没有说明文档的项目，无法验证其实际业务价值。

> 注：本文所有点名项目的各项数据与星数，均基于 2026 年 10 月 27 日的 GitHub API 数据快照。

# 一、四大现象级当红框架：重新定义 AI 成片

得益于 Claude Opus 5.5、GPT-6 Astra 等底层大模型能力的跃升，有四个项目在近期脱颖而出，成为了开发者圈子里当红的“辣子鸡”。它们分别在代码风格渲染、艺术动画、商业流程和手绘领域做到了极致。

## 1. lemo-opuscar：彻底抛弃视频大模型的风格引擎

lemomo-ai/lemo-opuscar（8,322 星）并不是一个简单的 Awesome 资源清单，而是一套开箱即用、可直接调用的视觉风格引擎。

它内置了 59 种针对 Claude Opus 5.5 深度调优的代码影片风格，每一种都标配风格提示词与纯代码渲染的样片，全程无需调用任何昂贵的 AI 视频生成模型。其代表作“OPUSCAR 98”是一支长达 6 分 31 秒的震撼样片，一次性展现了 98 种奥斯卡级别的 2D、2.5D 与 3D 视觉风格。

近期，该项目不仅新增了 8 种真实素材纪录片剪辑风格，还支持“将现有风格改造为专属资产”，并打通了 Claude 插件市场的一键安装。如果你需要现成的高级视觉方向，又想保留代码级修改的自由度，这是目前的绝对首选。

## 2. huashu-art-motion：艺术风格与解说语法的完美封装

alchaincyf/huashu-art-motion（5,418 星）是由开发者“花叔”开源的艺术动画 Skill。

它不仅仅提供颜色和纹理，而是将 36 种艺术风格、9 种解说语法和 8 种参数化片段整合进了一套完整的制作方法论中。仓库样片不仅有 65 秒的马里奥关卡重现，还有长达 98 秒、纯代码合成配乐的 Clawd 博物馆夜巡动画。

与 lemo-opuscar 偏向“提供素材与模板”不同，huashu-art-motion 解决了“如何用特定的视觉语法去讲解一段内容”的核心痛点，非常适合制作极具品牌辨识度的无口播动画或高级讲解片。

## 3. huashu-motion：商业发布片与“指哪打哪”的浏览器可视化修改

同样出自花叔之手的 alchaincyf/huashu-motion（1,766 星），精准切入了商业产品发布片的自动化生产。

它的 Agent 工作流极其清晰：读取产品信息 ➔ 给出三个商业策划方向 ➔ 确认后自动写出整片 ➔ 使用 ABC 记谱法在本机完成合成音色或真实乐器采样的配乐。

它最大的杀手锏是浏览器内可视化修改。在制作商业宣传片时，第一版往往只是草稿。通过这个工具，你在预览时只需按下 C 键，点击画面中的任意一帧并输入修改意见，Agent 就能像外科手术一样精准调整该处细节。这种“指着画面提意见”的交互，极大地提升了商业交付的效率。

## 4. sweety-handdraw-video：CodeX 友好的手绘口播全自动流水线

threerocks/sweety-handdraw-video（903 星，v1.4.1 版本）是一个极具普适性的明星项目。与其他强依赖 Claude Opus 5.5 的工具不同，它对 CodeX 极其友好，这对于无法稳定调用 Claude 的开发者来说是巨大的利好，同时它也全面兼容 Workbuddy 和 Opus 5.5，并且已经在 Workbuddy 技能市场上架，是极少数多平台支持的项目。

你只需输入一个主题、文章或定稿，Agent 就能自动包揽口播稿、分镜与插画设计；随后，本地渲染引擎将接手精准描线、自动上色、按笔顺生成手写字，并实现画面与配音的帧级对齐。

依托于极度拟人化的底层绘制引擎，以及原生集成的 VoxCPM 2 语音合成方案，观众可以直观地看到知识“逐步画出来”的动态过程。这是目前做知识科普、文章可视化最高效的可复用闭环流水线。

# 二、场景深挖：其他值得重点关注的硬核项目

除了四大天王，我还从 300 多个库中筛选出了一批在垂直领域解决痛点的优秀方案。

## 1. 自动化剪辑与人机协同

- 全自动转录剪辑： browser-use/video-use。直接把原始素材扔进文件夹，Agent 依赖逐词转录自动下刀，剔除语气词和停顿，完成字幕与 FFmpeg 调色，动效再交给 HyperFrames 或 Remotion（需自备 ElevenLabs API Key）。注意：模型不直接看画面，它完全基于文本逻辑剪辑。

- 人机协同微调： 机器剪完后，如果需要人类介入时间线微调，OpenChatCut 和 BaoCut 是最佳选择。

- 低星前沿探索： 11 星的 fragua 跑在本地，无需 API Key 即可用 FFmpeg 完成竖屏去静音和烧录字幕；而 0 星黑马 cutloupe 极其大胆，它提供 MCP 和可视化时间线，通过 look 命令把真实渲染帧送回给模型，尝试解决“让模型看见自己剪的画面”这一行业难题。

## 2. 代码直出成片与结构化镜头卡

- 提示词宝库： awesome-opus5-5-videos 收录了高达 703 条 Opus 5.5 的代码成片提示词。遇到绝佳的特效，直接复制提示词喂给自己的 Agent 即可复刻。

- 工程化镜头卡： video-shotcraft 专为 Remotion 商业片打造，内含 152 张结构化的镜头配方卡和 209 个动效预览。

- 动效逆向工程： lovisdotio/motion2code 将现有动效视频逆向重建为内联 SVG 和 GSAP 时间线，支持精确定位到任意帧与原片进行严谨对照。

## 3. 知识讲解、AI 数字人与音乐 MV

- 知识讲解： Raven 能读取 GitHub 仓库的 Git 提交历史，自动生成两分钟的高清手绘讲解动画；stickman-video-director 则专为不露脸的火柴人科普频道量身定制。

- AI 数字人： lanshu-create-ai-presenter-video 坚持供应商中立，主打使用已有授权图生成合规的数字人；digital-human-koubo 极其敏捷，单图加文本即可通过 Renoise MCP 调取 Grok Video 做口型，并在生成前提供清晰的积分计费预估。

- 音乐视频： PDoomVideo 公开了极具研究价值的完整 MV 源代码；只有 9 星的 mondo-music-video 正在构建一整套音乐视频工作室的基础设施（早期项目，需自行配置服务密钥）。
