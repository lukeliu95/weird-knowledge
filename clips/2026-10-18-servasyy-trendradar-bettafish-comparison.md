## 原文

最近的 GitHub 简直是神仙打架！两个国产开源项目 TrendRadar 和 BettaFish 轮流霸占榜一，直接杀疯了。
它们凭什么这么火？它们能带你一脚踹开算法的“信息茧房”，让你看点真东西。

TrendRadar和BettaFish核心定位差异：
TrendRadar 是一个轻量级的热点聚合工具，主要解决信息过载问题，帮助用户高效获取关心的热点新闻。

BettaFish 则是一个专业的舆情分析系统，通过多智能体协作深度挖掘评论和情感趋势，打破信息茧房，还原全局舆情态势。

TrendRadar：轻量高效的热点聚合器
适合场景：日常追热点、内容创作、个人信息管理
多平台覆盖：自动抓取微博、知乎、抖音、B站等 11+ 主流平台热搜榜单
灵活推送：支持企业微信、飞书、钉钉、Telegram、邮件等多渠道通知
零门槛部署：支持 GitHub Actions/Pages/Docker，一键 Fork 即可使用
智能筛选：自定义关键词过滤，AI 分析趋势和内容摘要

BettaFish：专业的舆情分析系统
适合场景：品牌公关、舆情监控、投资决策、政府媒体
深度分析：多 Agent 协作，分析新闻内容和大量评论，提供情感/趋势/群体对比洞察
多模态支持：不仅分析图文，还能解析短视频内容
专业报告：自动生成结构化报告，支持历史追踪、预测和分群分析
对话式交互：用自然语言请求分析报告，像聊天一样获取洞察

如何选择？

追求高效信息获取和日常热点追踪，选择 TrendRadar；
需要深度舆情分析、情感挖掘和趋势预测，选择 BettaFish。
