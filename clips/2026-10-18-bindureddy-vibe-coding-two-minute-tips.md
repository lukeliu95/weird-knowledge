## 原文

2-min vibe coding tutorial

- always start with something small
- create frequent checkpoints so that you can revert back to previous working versions
- deploy and test what you built. Don't be lazy, test what the agent has built
- make small incremental changes
- watch out for LLM hallucination

That's it!  That's all you need to do to succeed.

It's much easier to vibe code if you know how to write code.
