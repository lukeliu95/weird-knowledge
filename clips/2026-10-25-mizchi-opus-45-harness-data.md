## 原文

AIコーディングの潮目が変わったと言われる2025/11 の Opus 4.5、たぶんタイミング的に 2025/2 リリースの claude code 経由で突っ込まれたデータを取り込んで学習した時期なんだよな。
Open AI も Google もこぞってハーネス出してたから競合もハーネス経由でデータ集める意味に気づいてる

---

Opus 4.0 と Opus 4.5 の大きな違い、4.0 はコードを書かせたら基本的に発散してたのが、4.5 は適切に指示を与えるとリファクタできるようになった。自身のエントロピーを抑えられるようになったから、適切なハーネスがあれば自走できるようになった。ここがでかいと思う

## 溯源

- 核心主张：Opus 4.5 的能力跃升很可能来自经 Claude Code 这类外壳收集的使用数据，各家竞相发外壳就是为了收数据；而 4.5 能压住自己写代码时的发散（熵增），所以只要有合适的外壳就能自己跑。
- 源知识：
  - [数据飞轮](../roots/data-flywheel.md) · 关系：相近 · 强弱：弱（模型复核通过）。“发外壳→收用户写代码的数据→训出更强的模型→更多人用外壳”就是数据飞轮换成编程 agent 的说法；作者没有用这个词。
  - [外壳工程（agent = 模型 + 外壳）](../roots/harness-engineering.md) · 关系：相近 · 强弱：弱（模型复核通过）。“有合适的外壳就能自走”对应 agent = 模型 + 外壳：模型够稳之后，外壳决定它能不能独立完成任务。
  - [雷曼软件演化定律](../roots/lehmans-laws-of-software-evolution.md) · 关系：相近 · 强弱：弱（模型复核通过）。“写代码会发散、要能压住自身熵增才能重构”和雷曼复杂度递增定律同构：软件每改一次复杂度就上升，除非专门投入工作去降低它。
- 本质：这条新知识本质上是数据飞轮在大模型厂商与编程 agent 外壳之间的应用，加上一条推断：模型能主动对抗代码复杂度递增之后，外壳才能放手让它自走。
