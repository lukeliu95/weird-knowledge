## 原文

Hello everyone!

The culmination of our experiences working with Qwen 3.8 is here! Qwopus 3.8 Coder Flash!

GGUF: https://t.co/zeHm4AnCJu

Qwen 3.8 heavily pushed toward software engineering large model teacher data, RL’d with a new reward approach, and it is the best of the line in my opinion. 

Of course right before Qwen 4 🤣 

It really is a joy to use in Claude code, the CoT behavior is particularly exceptional compared to the base and prior versions. Using it with the image tower unlocks some pretty incredible capabilities for self troubleshooting front end/rendering related queries.

The best way I can describe it, is it just works. No constant messing with settings, no half hour <think> sessions.

Something to note is that because this was pushed heavily towards programming data, it may digress in other use cases. However I’ve run some general queries through it as well and it seems to have retained decent capability of the generalist base.

If you have some time to play with it this week before Qwen 4, please let us know your thoughts below! Jack really cooked on the COT process flow, please see the full model card for more details and GGUF’s

We’re so pumped to get new weights from @Alibaba_Qwen this week! 

Let the festivities continue! Blessed to be here and grateful for the community, have a wonderful week!
