### 内容要点（模型概括，不是原文）

**要解决的问题**

现在评测客服、电商这类 agent，主要靠让大模型扮演用户（比如 τ-bench）。但大模型扮的用户不像真人：太配合、文风千篇一律、没有真实的烦躁和含糊，会把 agent 的成绩抬高，把上线后才会暴露的毛病藏起来（第 1 节）。

作者把原因归成两条（第 1 节）：

- **"太正规"天花板**（Formalism Ceiling）：不给任何约束时，模拟器总是写语法正确、标点齐全、又长又客气的话，不管要扮的那个人平时怎么说话。在文风相关的几个维度上，和真人对得上的比例只有 6%～8%
- **"指令放大"**（Directive Amplification）：人手写的行为指令，比如"你是一个很生气的客户"，会被模型过度演绎，写出"*抽泣*"这种舞台动作、一条消息塞好几个要求，真人不会这样。而且同一句指令在不同模型上效果差得很远，导致换一个模拟器模型，基准分数就没法比

同期的 Seshadri 等 2026、Zhou 等 2026 已经诊断出"模拟用户不像真人"，但只诊断不给办法。本文说自己给的是办法：从真实用户数据里提取行为画像，拿来约束模拟器（第 1、2 节）。

**核心想法**

不用虚构的人设，用真人留下的对话来定"这个用户怎么说话"。关键是画像的写法：不写"非正式的写作者"这种抽象描述，而是写成"可执行的人设手册"，最多 15 对"指令 + 原话例子"。指令说要模仿什么习惯，例子说模仿到什么程度（第 3.1 节）。

作者强调画像只管"怎么说"，不管"知道什么"（第 2 节、第 5.1 节）。

**主要方法**

| 项 | 设定 | 出处 |
|---|---|---|
| 数据来源 | WildChat-4.8M（真人和 ChatGPT 的公开对话日志）。从 320 万段筛到 21,637 段多轮（3 轮以上）英文 GPT-4o 对话，涉及 7,311 位用户；最后整理出 13,998 段 | 第 3.1 节，附录 A.1 |
| 文风画像 | GPT-4o 读每位用户的全部对话，按大小写、标点、消息长短、正式程度、术语、问候语、表情、每轮提几个要求这 8 个方面写"指令 + 例子"，例子从用户原话里摘。平均每份 9.4 条指令；共 7,275 份（覆盖 99.5% 的用户） | 第 3.1 节，附录 A.3、B |
| 人口画像 | 先抽用户自己说出来的年龄、学历、性别、职业等，多段对话投票；缺的再用模型推断。推断在 800 个检验样本上只敢答 33%，答了的准确率 64.4%（性别 85.4%、收入 50.0%） | 第 3.1 节，附录 A.2、表 7 |
| 像不像真人怎么测（PT3，成对轨迹图灵测试） | 从真实对话的前 10 条消息里抽出"要办的事"，让模拟用户和 GPT-4o agent 重新聊一遍（最多 9 条 agent 消息）。GPT-4o 裁判不看标签，并排看真对话和模拟对话，在 5 个维度上各判"对得上 / 对不上"，5 个维度的平均就是保真度 | 第 3.2 节，表 1 |
| 5 个维度 | 性格与情绪、语言风格（用词、错别字、长短）、技术水平与知识、给信息的方式、节奏与收尾 | 表 1 |
| 测试集 | 600 段对话、504 位用户：5 个行业各 100 段（科技、商业金融、医疗、电商、旅游），外加跨 71 个领域的混合集 100 段；每位用户最多 2 段 | 第 3.2.2 节，附录 D |
| 防泄题 | 画像是用用户全部对话做的，例子可能就来自被测的那段。所以：只有一段对话的用户，例子全删、只留指令（150 例）；有多段的，删掉来自被测对话的例子（380 例）；70 例不用改 | 第 3.2.2 节 |
| agent 评测 | τ-bench 航空（50 题）和零售（114 题），agent 固定用 GPT-4.1；换 6 种模型当模拟用户：GPT-4o、GPT-5-mini、GPT-5、Llama 3-70b、gpt-oss-20b、Claude 3 Sonnet | 第 4.2 节 |
| 三种条件 | 原版（τ-bench 自带"你很生气"这类行为指令）；去掉指令只留任务（用 GPT-4o 把事实和语气拆开）；只留任务再加一份随机抽的真实用户画像（3 次随机抽取取平均） | 第 4.2 节，附录 C.3 |

**主要结果**

| 结果 | 数字 | 出处 |
|---|---|---|
| 加画像后整体更像真人 | 保真度 24.2% → 45.3%（+21.1 个点），600 段、每种条件 3,000 次判断 | 第 5.1 节、表 2 |
| 涨在文风相关的维度 | 性格与情绪 7.2% → 39.0%；给信息的方式 7.7% → 36.0%；节奏与收尾 6.5% → 32.0%；语言风格 6.2% → 26.2% | 表 2 |
| 知识维度本来就高，不变 | 技术水平与知识 93.3% → 93.2%；科技行业里反而从 99% 掉到 89%，因为画像是一个人的平均水平，会把某段对话的专业度演过头 | 第 5.1 节、表 2 |
| 各行业都涨 | 涨幅 +16.6（科技）到 +24.8（商业金融）；电商最高，40.4% → 59.4% | 表 2 |
| 最难的是"写得乱" | 语言风格加画像后也只有 26.2%：明说要错别字，GPT-4o 也写不出真正乱的字。只有一段对话的用户比例越高（例子被删光），这一项越低：旅游（41% 是这种用户）17.0%，商业金融（24%）30.0% | 第 5.1 节 |
| 换成真人文风，agent 成功率下降 | 和"只留任务"相比，航空平均 −3.2 个点（6 个模型里 5 个降），零售 −3.5 个点（4 个降）。Llama 3-70b 降最多（航空 −10.0，零售 −6.1）；gpt-oss-20b 两个领域相反（航空 +7.3，零售 −15.5） | 第 5.2.1 节、表 4 |
| 人写的行为指令反而制造了假难度 | 零售里，去掉指令后 6 个模型全部变好，最多 +16.7（GPT-4o，60.5% → 77.2%）；航空平均几乎不变（−0.3） | 第 5.2.1 节、表 4、图 2 |
| 指令放大的样子 | "你非常难过"：Llama 3-70b 写出"*抽泣* *哽咽*"，GPT-4o 只写"我现在真的很难过"。加不加指令：GPT-5-mini 带烦躁词的消息 16.7% 对 2.1%，平均消息长 1,218 对 514 字符；GPT-4o 几乎不受影响（1.2% 对 0.9%） | 第 5.2.3 节、表 6 |
| 不加指令时都一样客气 | 6 个模型默认都是配合型用户：GPT-4o 平均每条 122 字符，GPT-5-mini 494 字符、72% 的消息有 3 行以上。作者据此说原版 τ-bench 里的激烈行为全是指令造出来的 | 第 5.2.3 节，附录 E、表 8 |
| 真人文风让 agent 出错的三种方式 | 漏信息：简短的用户说"按刚才的取消"，agent 多取消了 2 张单；被语气带偏：全大写的"GIMME A REFUND PLS"被当成取消订单；太好说话：剧本要求坚持退款 5 次再放弃，犹豫型用户第一次就说"好吧取消吧" | 第 5.2.2 节、表 5 |
| 有的模型反而变好 | Claude 3 Sonnet 默认太配合，会主动说出该保留的信息；配上简短强硬的真人文风后零售 +3.5。它也是唯一一个随机真人画像（76.3%）比"完美用户"（71.1%）还好的模型 | 第 5.2.3 节，附录 G.3 |
| 一次跑分不够用 | 同一模型换 3 次随机画像，航空平均相差 8.0 个点，零售 5.9 个点；Claude 3 Sonnet 航空从 42% 到 56%。连不加画像的基线重跑也会差 8 个点（GPT-4o 航空 42% 对 50%） | 附录 G.1 |
| 文风正式的人更容易被服务好 | 零售里，6 个模型中有 4 个是"高学历画像"成功率高于"低学历"，最大差 15.8 个点（gpt-oss-20b）；"最年长"高于"年轻"也是 4 个，平均高 3.1 个点。作者认为起作用的是说话正式、有条理，不是年龄学历本身 | 附录 G.2、表 9、表 10 |
| "完美用户"上限 | 专门设计一个配合、清楚、果断的用户：GPT-5-mini 零售从 50.9% 升到 71.1%（+20.2） | 附录 G.3 |

**作者的结论**（第 6 节）

- 带画像的模拟器明显更像真人，而且在严格防泄题下各行业都成立
- 真人画像是一种"真实的压力测试"，能找出配合型模拟器发现不了的失败
- 现有基准里人写的行为指令会被放大成不真实的行为，损害评测的可信度
- 可靠的 agent 评测必须拿真实交互数据来约束模拟用户，而不是靠合成出来的极端行为

**需要说清楚的边界**

- 论文没有单独的"局限"一节，下面多数是读全文后标出来的，不是作者自己承认的
- 作者自己说的：WildChat 用户偏年轻、偏高学历（75% 不到 25 岁，46% 本科），"最年长"组（55 岁以上）只有 38 份画像，"年轻"组有 1,385 份（附录 A.2）；人口画像缺得多，平均完整度只有 0.25（附录 B、图 4）；单次跑分统计上不够，小的差别不可靠（附录 G.1）
- "像不像"全靠 GPT-4o 一个裁判判断，没有人工核对；画像也是 GPT-4o 写的，被测的模拟器也是 GPT-4o，同一家模型自己出题、自己答、自己判（第 3.2、4.1 节）。技术维度基线就有 93.3%，裁判可能偏宽
- 加画像后保真度也只有 45.3%，一半以上的判断仍然"对不上"（表 2）
- agent 成功率平均降 3.2～3.5 个点，比同一模型换一次随机画像的波动（5.9～8.0 个点，附录 G.1）还小；论文没有给显著性检验。所以"真人文风让 agent 变差"的方向可信度一般，具体幅度不要当真
- 只模拟了"怎么说"（文风），没模拟"愿不愿意、会不会走开"这类决定。Chen 2026 正是在这一点上补充：说话像了，不等于做决定像了
- 画像来自人和 ChatGPT 的闲聊、写作、问答，不是客户和客服、销售的对话；放到 τ-bench 时是随机抽画像配题目，不是同一个人办同一类事
- 只有英文；测试集按质量分取前 100，偏向更长、更投入的对话（附录 D）
- "第一个用真实行为数据约束用户模拟的框架"是作者自己的说法；引用里的 Wang 等 2025a（从隐含画像建模像人的模拟器）方向相近，两者差在哪，论文只用一句话带过，待查
- 用的 Claude 3 Sonnet、Llama 3-70b 是较早的模型；论文页眉写"在投"，未同行评审；没有给出代码和画像数据的公开地址
- 正文和图里的用户数有 7,275、7,273、7,311 三种写法，分别对应不同的筛选阶段，没逐一说明
