## 原文

AI 能操作手机啦！

继 BrouserUse, ComputerUse 等等后，PhoneUse 类的项目终于出现了 —— DroidRun 

这个项目可以让你的 AI Agent 操作手机，并且将视觉理解与 UI 结构提取相结合，实现全面的网页交互。

目前项目刚放出了视频和官方页面，据作者说马上就会开源并推送到 Github
