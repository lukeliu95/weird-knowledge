## 原文

别再手动写 Claude Code 的 skill 了。

autoharness 会自动盯着你的会话，把重复出现的工作流直接变成 skill。

它能做到：

• 从已完成的会话里学习
• 用 /learn 立刻保存经验
• 合并重复的 skill
• 在 skill 被使用时同步更新
• 把过期的归档
• 你手写的 skill 完全不动

同一个模型，更强的 harness：有人报告说，光换这套配置就把 CORE-Bench 从 42% 拉到了 78%。

纯 Python，零依赖，100% 开源。
